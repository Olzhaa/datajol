CP1 C++: C++ қазақша: функциялар, vector, pointer, класстар, STL, браузерде код жазу

C++ негіздері: cout/cin, типтер, string, шарттар мен циклдер, функциялар мен reference, vector, pointer және динамикалық жад, класстар, operator overloading, template, мұрагерлік, STL және рекурсия. Әр тапсырма — stdin-нен оқып, stdout-қа жазатын толық бағдарлама; соңында Оңай / Орташа / Қиын есептер жинағы мен емтихан.

Тапсырмаларды орындау

1. Алғашқы бағдарлама: main, cout, cin

C++ — жылдамдыққа арналған компиляцияланатын тіл: ойын қозғалтқыштары (Unreal Engine), браузерлер, дерекқорлар, тіпті PyTorch пен NumPy-дың ішкі ядросы осы тілде жазылған. Python-нан айырмашылығы: код алдымен compiler арқылы машиналық кодқа аударылады, содан кейін ғана іске қосылады. Қате көбіне іске қосудан бұрын, компиляция кезінде табылады.

Бағдарлама құрылымы

#include <iostream>      // енгізу/шығару кітапханасы
using namespace std;     // std:: деп әр жолы жазбау үшін

int main() {             // бағдарлама осы жерден басталады
    cout << "Сәлем, Алматы!" << endl;
    return 0;            // 0 — «бәрі сәтті аяқталды»
}
  • #include — кітапхананы қосады. cout мен cin <iostream> ішінде.
  • int main() — әр бағдарламада дәл біреу болатын кіру нүктесі.
  • Әр нұсқаулық нүктелі үтірмен ; аяқталады. Блоктар фигуралық жақшамен { } белгіленеді, шегініс (indentation) тек оқуға ыңғайлылық үшін.
  • cout << — экранға шығару; << арқылы бірнеше мәнді тізбектей береміз. endl — жаңа жол.

Енгізу: cin

int a, b;
cin >> a >> b;           // "3 4" немесе "3\n4" — екеуі де жұмыс істейді
cout << a + b << endl;   // 7

cin >> бос орын мен жаңа жолды өткізіп жібереді де, келесі мәнді айнымалының типіне қарай оқиды. Айнымалыны қолданбас бұрын оның типін жариялау міндетті: int a;.

DataJol-да әр тапсырма — толық бағдарлама. Тексеру кезінде оған дайын кіріс (stdin) беріледі, ал сіздің шығысыңыз (stdout) күтілген жауаппен жол-жолымен салыстырылады. Сондықтан артық мәтін («Санды енгізіңіз:» сияқты) шығармаңыз.

2. Типтер, айнымалылар және арифметика

C++ — статикалық типтелген тіл: әр айнымалының типі компиляция кезінде белгілі және кейін өзгермейді. Тип айнымалыға қанша жад бөлінетінін және онымен қандай амал жасауға болатынын анықтайды.

ТипНе сақтайдыМысал
intбүтін сан, шамамен ±2.1 млрдint age = 19;
long longүлкен бүтін сан, шамамен ±9.2·10¹⁸long long people = 8000000000LL;
doubleбөлшек санdouble price = 1299.5;
charбір символ (1 байт)char grade = 'A';
booltrue / falsebool paid = true;

auto типті компиляторға шығартады: auto x = 3.5; — double. const өзгермейтін мән жасайды: const int DAYS = 7;.

Бүтін санды бөлу — басты тұзақ

cout << 7 / 2 << endl;        // 3   — екі int: бөлшек бөлігі тасталады
cout << 7 % 2 << endl;        // 1   — қалдық
cout << 7.0 / 2 << endl;      // 3.5 — бір операнд double болса, нәтиже double
int total = 10000, n = 3;
double share = static_cast<double>(total) / n;   // 3333.33...

Назар аударыңыз: double d = 7 / 2; жазсаңыз, алдымен 7 / 2 бүтін ретінде есептеліп 3 шығады, содан кейін ғана 3.0 болып d-ге жазылады.

Overflow және бөлшекті шығару

int шегінен асып кетсе (overflow), C++ қате бермейді — мән «оралып» қате санға айналады. Қосынды, көбейтінді үлкен болуы мүмкін болса, long long алыңыз.

#include <iomanip>
double avg = 2250.0;
cout << fixed << setprecision(2) << avg << endl;   // 2250.00
fixed << setprecision(2) — ондық бөліктен кейін дәл 2 цифр. Бұл баптау келесі барлық double шығысына әсер етеді.

3. Жолдар: std::string

C++-та мәтін std::string класында сақталады (#include <string>). Ол Python жолына ұқсайды, бірақ өзгермелі: жеке символды тікелей ауыстыруға болады.

string city = "Astana";
cout << city.size() << endl;        // 6
cout << city[0] << endl;            // A  (char)
city[0] = 'a';                      // "astana" — өзгертуге болады
string full = city + " city";       // біріктіру
cout << city.substr(1, 3) << endl;  // "sta": 1-позициядан бастап 3 символ
cout << city.find("na") << endl;    // 3; табылмаса string::npos
string s = to_string(2025);         // сан → жол
int n = stoi("42");                 // жол → сан

cin және getline

cin >> s бір сөзді оқиды: бос орынға жеткенде тоқтайды. Бүкіл жолды оқу үшін getline керек:

string line;
getline(cin, line);       // "Нұр Сұлтан даңғылы 12" — толық жол

Егер алдымен cin >> n, сосын getline қолдансаңыз, бірінші жолдың соңындағы жаңа жол символы қалып қояды да, getline бос жол оқиды. Шешімі — арасында cin.ignore(); шақыру.

Символдармен жұмыс

for (char c : line) {                // range-based for
    if (c == ' ') continue;
    char up = toupper(c);            // 'a' → 'A'
}
Кирилл және UTF-8: size() символдарды емес, байттарды санайды. Латын әрпі — 1 байт, ал «Ә», «Қ» сияқты қазақ әріптері — 2 байт. Сондықтан string("Қала").size() 8 болады. Символ деңгейіндегі тапсырмаларда біз латын мәтінін қолданамыз.

4. Шарттар: if/else және switch

Бағдарлама шартқа қарай әртүрлі жол таңдайды. Салыстыру операторлары: == != < > <= >=; логикалық: && (және), || (немесе), ! (емес). Шарт жақшаға алынады.

int temp;
cin >> temp;
if (temp < 0) {
    cout << "Суық" << endl;
} else if (temp <= 15) {
    cout << "Салқын" << endl;
} else {
    cout << "Жылы" << endl;
}
string status = (temp > 30) ? "Ыстық" : "Қалыпты";   // тернарлы оператор

Тұзақ: if (x = 5) — бұл салыстыру емес, меншіктеу. Шарт әрқашан ақиқат болады. Салыстыру үшін == жазыңыз (компилятор көбіне ескерту береді).

switch

Бір бүтін (немесе char) мәнді бірнеше нақты мәнмен салыстырғанда switch ықшам:

char cmd;
cin >> cmd;
switch (cmd) {
    case 'D': cout << "Депозит" << endl; break;
    case 'W': cout << "Ақша алу" << endl; break;
    case 'q':
    case 'Q': cout << "Шығу" << endl; break;   // екі case бір блокта
    default:  cout << "Белгісіз команда" << endl;
}

break маңызды: оны ұмытсаңыз, орындау келесі case-ке «құлап түседі» (fallthrough) және оның кодын да орындайды. switch string немесе double мәнмен жұмыс істемейді — ондай жағдайда if/else if тізбегін қолданыңыз.

C++-та 0 — жалған, кез келген басқа сан — ақиқат. Сондықтан if (n % 2) «n тақ болса» дегенді білдіреді.

5. Циклдер: for, while, do-while

Цикл бір әрекетті көп рет қайталайды. C++-та үш негізгі түрі бар.

for (int i = 1; i <= 5; i++) {     // бастау; шарт; қадам
    cout << i << " ";              // 1 2 3 4 5
}

int balance = 1000;
int months = 0;
while (balance < 2000) {           // шарт ақиқат болғанша
    balance += balance / 10;       // ай сайын 10% өсім
    months++;
}

int pin;
do {
    cin >> pin;                    // кемінде бір рет орындалады
} while (pin != 1234);

break циклден бірден шығады, continue осы айналымның қалғанын өткізіп, келесісіне өтеді. Цикл ішінде цикл (nested loop) кесте не үшбұрыш сияқты екі өлшемді құрылымдарға керек:

for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= i; j++) cout << "*";
    cout << endl;
}
// *
// **
// ***

Кіріс біткенше оқу

Сандар саны алдын ала белгісіз болса, while (cin >> x) қолданыңыз: оқу сәтсіз болғанда (кіріс біткенде, EOF) шарт жалған болады.

long long sum = 0;
int x;
while (cin >> x) sum += x;
Қосынды үлкен болуы мүмкін болса, long long алыңыз: 1-ден 100 000-ға дейінгі сандардың қосындысы 5 000 050 000 — бұл int шегінен асады.

6. Функциялар, overloading және reference

Функция кодты атауы бар блокқа бөледі. C++-та функцияның қайтаратын типі, аты және параметр типтері жазылады. Ештеңе қайтармайтын функция — void.

int square(int x) {
    return x * x;
}
void greet(string name, string greeting = "Сәлем") {   // әдепкі аргумент
    cout << greeting << ", " << name << "!" << endl;
}

Функция қолданылмас бұрын жарияланған болуы керек. Оны main-нен кейін жазғыңыз келсе, алдында прототипін беріңіз: int square(int x);.

Мән бойынша және reference бойынша беру

Әдепкіде аргумент көшіріледі (pass by value): функция ішіндегі өзгеріс сыртқы айнымалыға әсер етпейді. & белгісі бар параметр — reference, яғни сол айнымалының өзіне екінші ат:

void addBonusCopy(int salary) { salary += 50000; }      // сырттағы мән өзгермейді
void addBonus(int& salary)    { salary += 50000; }      // сырттағы мән өзгереді

int s = 300000;
addBonusCopy(s);   // s == 300000
addBonus(s);       // s == 350000

Үлкен нысанды (string, vector) көшірмей, бірақ өзгертпей беру үшін const reference қолданылады: int countSpaces(const string& text). Бұл — C++-тағы ең жиі кездесетін параметр түрі.

Overloading

Бір атпен бірнеше функция жазуға болады, егер параметрлерінің саны не типі әртүрлі болса. Компилятор шақырудағы аргументтерге қарап дұрысын таңдайды:

int    area(int side)              { return side * side; }
double area(double r, bool circle) { return 3.14159 * r * r; }
int    area(int w, int h)          { return w * h; }
Тек қайтаратын типі әртүрлі функцияларды overload жасауға болмайды: int f(int) мен double f(int) — қате, себебі шақыруда f(3) қайсысы екені белгісіз.

7. Массив және std::vector

C-массив — бір типті элементтердің бекітілген өлшемді тізбегі: int a[5] = {4, 8, 15, 16, 23};. Оның өлшемі компиляция кезінде белгілі болуы керек және өзгермейді. Ең қауіптісі — C++ индекстің шекарадан шығуын тексермейді: a[10] қате бермейді, тек бөтен жадты оқиды (undefined behavior).

std::vector — динамикалық массив

Күнделікті жұмыста vector (#include <vector>) қолданылады: ол өз өлшемін біледі және қажет болғанда өседі.

vector<int> prices;                 // бос
prices.push_back(1200);             // соңына қосу
prices.push_back(850);
cout << prices.size() << endl;      // 2
cout << prices[0] << endl;          // 1200 (тексерусіз)
cout << prices.at(1) << endl;       // 850  (шекараны тексереді)
prices.pop_back();                  // соңғысын өшіру

int n;
cin >> n;
vector<int> a(n);                   // n нөлден тұратын вектор
for (int i = 0; i < n; i++) cin >> a[i];

long long sum = 0;
for (int x : a) sum += x;           // range-based for

vector<int> v(3) — үш нөл; vector<int> v(3, 7) — үш жеті. Екі өлшемді кесте — вектордың векторы:

vector<vector<int>> grid(3, vector<int>(4, 0));   // 3 жол, 4 баған
grid[1][2] = 5;

Векторды функцияға reference арқылы беріңіз: void fill(vector<int>& v) — өзгерту үшін, int total(const vector<int>& v) — тек оқу үшін. Әйтпесе бүкіл вектор көшіріледі.

Индекспен цикл жазғанда i < v.size() шартында size() таңбасыз (size_t) тип қайтарады. Бос векторда v.size() - 1 өте үлкен санға айналады — абай болыңыз.

8. Pointer және динамикалық жад

Әр айнымалы жадта бір адресте орналасады. Pointer (көрсеткіш) — адресті сақтайтын айнымалы. Python мен Java мұны жасырады, ал C++ жадпен тікелей жұмыс істеуге мүмкіндік береді — сондықтан жылдам, бірақ қателесу оңай.

int balance = 5000;
int* p = &balance;      // &balance — balance-тің адресі
cout << *p << endl;     // 5000: * — адрестегі мәнді алу (dereference)
*p += 1000;             // balance енді 6000
int* q = nullptr;       // ешқайда көрсетпейтін pointer

int& r = x (reference) мен int* p = &x (pointer) ұқсас, бірақ reference әрқашан бір нысанға байланған және null бола алмайды, ал pointer-ді басқа адреске ауыстыруға және nullptr етуге болады.

Stack және heap

Жергілікті айнымалылар stack-те тұрады және функциядан шыққанда өздігінен жойылады. Өмір сүру уақыты ұзақ немесе өлшемі тек іске қосылғанда белгілі болатын деректер heap-те new арқылы бөлінеді, және оларды delete арқылы өзіңіз босатуыңыз керек:

int* one = new int(42);
int* arr = new int[n];     // n элементті массив
// ... қолдану ...
delete one;
delete[] arr;              // массив үшін delete[]

Үш классикалық қате: memory leak (delete ұмытылды — жад біртіндеп таусылады), dangling pointer (жад босатылған, бірақ pointer әлі сол адреске қарайды) және double delete (бір жадты екі рет босату).

Smart pointer: неге қолмен delete жазбаймыз

Қазіргі C++ (<memory>) жадты RAII принципімен басқарады: иесі жойылғанда ресурс өздігінен босайды.

#include <memory>
unique_ptr<int> a = make_unique<int>(10);   // жалғыз иесі бар
shared_ptr<string> s = make_shared<string>("Kaspi");
auto s2 = s;                                 // екі иесі; соңғысы жойылғанда жад босайды
// delete жазудың қажеті жоқ
Ереже: жаңа кодта new/delete орнына vector, string, unique_ptr қолданыңыз. Шикі pointer-ді тек «иелік етпей, қарап тұру» үшін ұстаңыз. Ескерту: браузердегі компиляторда жад қорғанысы жоқ — қате pointer бағдарламаны құлатпай, қоқыс мән береді.

9. struct, class, constructor және destructor

struct бірнеше өрісті бір типке біріктіреді. class — сол идея, бірақ әдепкіде өрістері жабық (private). Айырмашылық тек әдепкі қолжетімділікте: struct-та public, class-та private.

struct Student {
    string name;
    int score;
};
Student s{"Дана", 91};
cout << s.name << " " << s.score << endl;

Инкапсуляция және constructor

Класс деректерді жасырып, оларға тек дұрыс әдістер арқылы қол жеткізуге мүмкіндік береді. Constructor — нысан жасалғанда шақырылатын, класпен аттас, қайтару типі жоқ функция. Өрістерді initializer list арқылы толтырған дұрыс:

class Account {
private:
    string owner;
    long long balance;
public:
    Account(string o, long long b) : owner(o), balance(b) {}
    void deposit(long long x) { if (x > 0) balance += x; }
    bool withdraw(long long x) {
        if (x > balance) return false;   // жеткіліксіз — бас тарту
        balance -= x;
        return true;
    }
    long long getBalance() const { return balance; }   // const: нысанды өзгертпейді
};

Account acc("Ерлан", 10000);
acc.withdraw(3000);
// acc.balance = 1000000;   // қате: balance — private

Destructor

Destructor ~ClassName() нысан жойылғанда (мысалы, scope-тан шыққанда) өздігінен шақырылады. Онда ресурстар босатылады: жад, файл, желі байланысы. Бұл — RAII (Resource Acquisition Is Initialization): ресурсты constructor алады, destructor қайтарады.

struct Logger {
    string name;
    Logger(string n) : name(n) { cout << "open " << name << endl; }
    ~Logger() { cout << "close " << name << endl; }
};
int main() {
    Logger a("A");
    Logger b("B");
}   // шығыс: open A, open B, close B, close A
Жергілікті нысандар құрылған ретіне кері ретпен жойылады: соңғы жасалған — бірінші жойылады (stack сияқты).

10. Operator overloading және template

Өз типіңізді кірістірілген типтер сияқты қолдануға болады: a + b, a == b, cout << a. Ол үшін операторды overload жасайсыз — бұл operator+ деген атаулы кәдімгі функция.

struct Money {
    long long tiyn;       // 1 теңге = 100 тиын
};
Money operator+(const Money& a, const Money& b) {
    return Money{a.tiyn + b.tiyn};
}
bool operator<(const Money& a, const Money& b) {
    return a.tiyn < b.tiyn;            // енді sort() Money-ді сұрыптай алады
}
ostream& operator<<(ostream& os, const Money& m) {
    os << m.tiyn / 100 << "." << m.tiyn % 100 / 10 << m.tiyn % 10 << " ₸";
    return os;                         // тізбектеу үшін ағынды қайтарамыз
}
Money a{150050}, b{99950};
cout << a + b << endl;                 // 2500.00 ₸

operator<< ostream& қайтарады — сонда cout << a << b тізбегі жұмыс істейді. Операторды мағынасына сай overload жасаңыз: + қосу сияқты әрекет етуі керек.

Template: бір код — көп тип

int, double және string үшін бірдей функцияны үш рет жазбау үшін template қолданылады. T — компилятор кейін нақты типпен алмастыратын орын:

template <typename T>
T biggest(T a, T b) {
    return (a < b) ? b : a;
}
biggest(3, 9);                         // T = int
biggest(string("alma"), string("anar"));   // T = string

template <typename T>
class Box {
    T value;
public:
    Box(T v) : value(v) {}
    T get() const { return value; }
};
Box<double> price(1299.5);

Компилятор әр қолданылған тип үшін жеке нұсқаны компиляция кезінде жасайды (instantiation), сондықтан template жылдам: іске қосылғанда қосымша шығын жоқ. Сіз бұған дейін template-терді қолдандыңыз: vector<int>, unique_ptr<T>, map<K, V> — бәрі класс template-тері.

Template-тегі T типі ішінде қолданылған амалдарды қолдауы керек. biggest үшін T-да < болуы шарт — сондықтан Money-ге operator< жазсаңыз, biggest(m1, m2) да жұмыс істейді.

11. Мұрагерлік және virtual функциялар

Мұрагерлік (inheritance) жаңа класты бар класқа негіздеп жасауға мүмкіндік береді: туынды класс (derived) базалық класстың (base) өрістері мен әдістерін алады және өзінікін қосады.

class Shape {
public:
    virtual double area() const = 0;   // pure virtual: Shape абстрактілі
    virtual ~Shape() {}                 // virtual destructor
};
class Circle : public Shape {
    double r;
public:
    Circle(double r) : r(r) {}
    double area() const override { return 3.14159265358979 * r * r; }
};
class Rect : public Shape {
    double w, h;
public:
    Rect(double w, double h) : w(w), h(h) {}
    double area() const override { return w * h; }
};

Полиморфизм: virtual не береді

Base-ке pointer не reference арқылы туынды нысанмен жұмыс істеуге болады. virtual әдіс шақырылғанда, pointer-дің типіне емес, нысанның нақты типіне қарап таңдалады (dynamic dispatch):

vector<unique_ptr<Shape>> shapes;
shapes.push_back(make_unique<Circle>(1.0));
shapes.push_back(make_unique<Rect>(2, 3));
double total = 0;
for (const auto& s : shapes) total += s->area();   // Circle::area, Rect::area

virtual жазылмаса, s->area() әрқашан Shape::area-ны шақырады (static binding) — бұл жиі кездесетін қате. override кілт сөзі компиляторға «мен base-тегі virtual әдісті алмастырамын» дейді: атауда қате болса, компилятор бірден ескертеді.

  • = 0 — pure virtual: базада іске асыру жоқ, ондай класстың нысанын жасауға болмайды (абстрактілі класс, Java-дағы interface-ке ұқсас).
  • protected — сырттан жабық, бірақ туынды класстарға ашық өрістер.
  • Base-ке pointer арқылы delete жасалатын болса, base destructor virtual болуы керек — әйтпесе туынды класстың destructor-ы шақырылмайды.
s->area() — (*s).area() дегеннің қысқа жазылуы: pointer арқылы мүшеге қол жеткізу.

12. STL: sort, map, set, unordered_map

STL (Standard Template Library) — дайын контейнерлер мен алгоритмдер жинағы. Олар template, сондықтан кез келген типпен жұмыс істейді.

algorithm

#include <algorithm>
vector<int> v = {5, 2, 9, 1};
sort(v.begin(), v.end());                           // 1 2 5 9
sort(v.begin(), v.end(), greater<int>());           // 9 5 2 1
reverse(v.begin(), v.end());
int mx = *max_element(v.begin(), v.end());          // итератор → * арқылы мән
int cnt = count(v.begin(), v.end(), 5);

// lambda арқылы өз ретіңіз: балл кемуі, тең болса аты бойынша
sort(st.begin(), st.end(), [](const Student& a, const Student& b) {
    if (a.score != b.score) return a.score > b.score;
    return a.name < b.name;
});

v.begin(), v.end() — итераторлар: контейнердің басы мен соңынан кейінгі орын. Алгоритмдер ауқымды осылай қабылдайды.

map, unordered_map, set

#include <map>
map<string, int> stock;               // кілттер сұрыпталған күйде (red-black tree)
stock["Алматы"] += 5;                 // жоқ кілт 0-мен автоматты құрылады
stock["Астана"] = 3;
for (const auto& [city, qty] : stock) // C++17 structured binding
    cout << city << " " << qty << endl;
if (stock.count("Шымкент") == 0) { /* жоқ */ }

#include <unordered_map>
unordered_map<string, int> freq;      // hash table: орта есеппен O(1), реті жоқ

#include <set>
set<int> seen = {5, 1, 5, 3};         // {1, 3, 5}: қайталанбайды, сұрыпталған
seen.insert(4);
КонтейнерІздеу/қосуРеті
map, setO(log n)кілт бойынша сұрыпталған
unordered_map, unordered_setорта есеппен O(1)ретсіз
Тұзақ: m[key] кілт жоқ болса, оны әдепкі мәнмен қосып қояды. Тек тексеру керек болса, m.count(key) не m.find(key) != m.end() қолданыңыз.

13. Рекурсия және қателерді өңдеу (exceptions)

Рекурсия — функцияның өзін-өзі шақыруы. Әр рекурсивті функцияда екі бөлік болады: базалық жағдай (тоқтау шарты) және есепті кішірейтетін рекурсивті қадам.

long long factorial(int n) {
    if (n <= 1) return 1;            // базалық жағдай
    return n * factorial(n - 1);     // рекурсивті қадам
}

// Backtracking: n ұзындықтағы барлық екілік жолдар
void gen(string cur, int n) {
    if ((int)cur.size() == n) { cout << cur << endl; return; }
    gen(cur + "0", n);
    gen(cur + "1", n);
}

Әр шақыру call stack-те жаңа фрейм ашады. Базалық жағдай болмаса не тым терең болса, стек толып кетеді (stack overflow). C++ стегі Python-ға қарағанда кеңірек, бірақ миллиондаған тереңдікке арналмаған — ондайда циклді қолданыңыз.

Exceptions: try, throw, catch

Кәдімгі C++-та күтпеген жағдай exception арқылы хабарланады. Функция throw арқылы қате нысанын лақтырады, ал шақырушы оны try/catch арқылы ұстайды:

#include <stdexcept>
double safeDivide(double a, double b) {
    if (b == 0) throw invalid_argument("нөлге бөлуге болмайды");
    return a / b;
}
try {
    cout << safeDivide(10, 0) << endl;
} catch (const invalid_argument& e) {
    cout << "Қате: " << e.what() << endl;
} catch (const exception& e) {        // кез келген стандартты қате
    cout << "Басқа қате" << endl;
}
  • catch блоктары жоғарыдан төмен тексеріледі; бірінші сәйкес келгені орындалады, сондықтан нақтырақ типтер жоғарыда тұрады.
  • stoi("abc") — invalid_argument, v.at(100) — out_of_range лақтырады.
  • Exception ешкім ұстамаса, бағдарлама std::terminate арқылы апатты түрде тоқтайды. Стек «шешілген» (stack unwinding) кезде жергілікті нысандардың destructor-лары шақырылады — RAII сондықтан маңызды.
DataJol-дағы браузер компиляторы -fno-exceptions режимінде жұмыс істейді: try/throw компиляцияланбайды. Ойын қозғалтқыштары мен embedded жүйелер де жиі осылай жасайды. Сондықтан тапсырмаларда қатені bool қайтару немесе арнайы мән (мысалы, -1) арқылы хабарлаймыз.

14. Есептер: Оңай және Орташа

Бұл сабақ — C++-тағы алгоритмдік есептер жинағы, LeetCode пен олимпиада стиліндегі шағын тапсырмалар. Әр есепте кірісті stdin-нен оқып, жауапты stdout-қа шығарасыз.

Олимпиада стиліндегі C++ шаблоны

#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
using namespace std;

int main() {
    ios::sync_with_stdio(false);   // cin/cout-ты жылдамдатады
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<long long> a(n);
    for (auto& x : a) cin >> x;
    // ... шешім ...
    return 0;
}
  • Шеткі жағдайлар: бір элемент, барлық элемент тең, теріс сандар, бос жауап.
  • Типтер: қосынды мен көбейтінді үшін long long.
  • Күрделілік: n ≤ 1000 болса O(n²) жеткілікті; n ≤ 10⁵ болса O(n log n) не O(n) керек.
  • Жауап форматы: артық мәтін, артық бос жол шығармаңыз.
Алдымен қағазға кішкентай мысалды қолмен шешіп алыңыз — алгоритм анық болса, C++ коды өздігінен жазылады.

15. Есептер: Орташа және Қиын

Бұл жинақтағы есептер интервью мен олимпиада деңгейінде: stack, sliding window, binary search, BFS және динамикалық бағдарламалау. Python-да DSA модулінде таныс болған идеяларды енді C++ STL-мен жүзеге асырасыз.

vector<int> v = {1, 3, 3, 5, 8};

int dr[4] = {1, -1, 0, 0};
