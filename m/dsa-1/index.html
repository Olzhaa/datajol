DSA Data Structures & Algorithms: Алгоритмдер мен деректер құрылымдары: Big-O, hash map, ағаш, граф, DP есептері

Алгоритмдер мен деректер құрылымдары: Big-O, массив пен екі көрсеткіш, hash map, stack/queue, linked list, рекурсия, binary search, сұрыптау, ағаш, heap, граф және динамикалық бағдарламалау. Әр тақырыптан кейін Python-да өзіңіз іске асырасыз, соңында Оңай / Орташа / Қиын деңгейлі есептер жинағын шешесіз.

Тапсырмаларды орындау

1. Big-O: алгоритмнің құнын санау

Бір тапсырманы екі түрлі кодпен шешуге болады: екеуі де дұрыс жауап береді, бірақ біреуі 1 000 тапсырыста жарты секундта, 1 000 000 тапсырыста сағаттап жұмыс істейді. Big-O — кіріс өлшемі n өскенде жұмыс көлемі қалай өсетінін сипаттайтын белгі. Нақты секундтар емес, өсу формасы маңызды.

Операцияларды санау

Kaspi-стильді дүкенде n тапсырыс бар. Сұрақ: бірдей order_id екі рет кездесе ме?

# 1-нұсқа: әр жұпты салыстыру
def has_dup_slow(ids):
    for i in range(len(ids)):
        for j in range(i + 1, len(ids)):
            if ids[i] == ids[j]:
                return True
    return False

# 2-нұсқа: көргенді set-ке жинау
def has_dup_fast(ids):
    seen = set()
    for x in ids:
        if x in seen:
            return True
        seen.add(x)
    return False

Бірінші нұсқада ішкі цикл (n−1) + (n−2) + … + 1 = n(n−1)/2 рет орындалады — бұл O(n²). Екіншісінде әр элементке бір рет қараймыз, ал set-те тексеру орта есеппен тұрақты уақыт алады — O(n). n = 100 000 болса, біріншісі шамамен 5 млрд салыстыру жасайды, екіншісі — 100 мың.

Практикалық бағдар: Python бір секундта шамамен 10⁷ қарапайым операция жасайды (браузерде одан да баяу). n = 10⁵ болса, O(n²) ≈ 10¹⁰ — сәтсіз, O(n log n) ≈ 2·10⁶ — лезде.

2. Массив, тізім және екі көрсеткіш

Python list — динамикалық массив: элементтер жадта қатар тұрады. Сондықтан индекс бойынша алу a[i] — O(1), соңына қосу append — орта есеппен O(1). Ал басына қосу a.insert(0, x) немесе a.pop(0) — O(n): қалған элементтердің бәрі бір орынға жылжиды.

Екі көрсеткіш (two pointers)

Көп есепте екі индекс ұстап, оларды бір-біріне қарай жылжытамыз. Мысал: баға тізімі сұрыпталған, сатып алушының бюджеті 10 000 ₸. Қосындысы дәл бюджетке тең екі тауар бар ма?

def pair_with_sum(prices, budget):
    i, j = 0, len(prices) - 1
    while i < j:
        s = prices[i] + prices[j]
        if s == budget:
            return (i, j)
        if s < budget:
            i += 1      # қосынды аз — арзанын қымбатырағымен ауыстырамыз
        else:
            j -= 1      # қосынды көп — қымбатын арзандатамыз
    return None

Неге дұрыс? Егер prices[i] + prices[j] < budget болса, prices[i] кез келген j' ≤ j-мен де аз береді, сондықтан i-ді тастай аламыз. Әр қадамда бір көрсеткіш жылжиды — барлығы O(n), ал барлық жұпты тексеру O(n²) болар еді.

Тағы бір үлгі — оқу/жазу көрсеткіші: сұрыпталған тізімнен қайталануларды орнында (in place) алып тастау. w — келесі жазатын орын, r — оқып жатқан орын. Жаңа мән кездессе, a[w] = a[r], w += 1.

Жиі қателер: (1) Цикл ішінде a.pop(0) қолдану — байқаусызда O(n²). (2) Тізімді аралап жатып одан элемент өшіру — индекстер жылжып, элементтер өткізіліп кетеді. (3) Екі көрсеткіш тек сұрыпталған тізімде жұмыс істейтінін ұмыту.

3. Жолдар (strings)

Python-да str — өзгермейтін (immutable) таңбалар тізбегі. s[i] — O(1), len(s) — O(1), бірақ s[i] = 'а' жазуға болмайды: кез келген «өзгеріс» жаңа жол жасайды. Бұдан маңызды салдар шығады:

# Баяу: әр += жаңа жол жасап, бұрынғыны көшіреді → O(n²) болуы мүмкін
out = ''
for ch in text:
    out += ch.upper()

# Дұрыс: бөліктерді тізімге жинап, соңында бір рет біріктіру → O(n)
parts = []
for ch in text:
    parts.append(ch.upper())
out = ''.join(parts)

Жиі кездесетін әдістер

  • s.lower(), s.upper() — қазақ әріптерімен де жұмыс істейді: 'ҚАЗАҚ'.lower() == 'қазақ'.
  • ch.isalnum(), ch.isalpha(), ch.isdigit() — таңба түрін тексеру.
  • s.split(), ' '.join(words), s.strip(), s[::-1] (аударылған көшірме).

Мысал: палиндром

«Қазақ» сөзі екі жақтан бірдей оқылады — бұл палиндром. Тыныс белгілері мен бос орындарды елемей тексеру үшін екі көрсеткіш қолданамыз: сол жақтан және оң жақтан әріп емес таңбаларды өткізіп жібереміз, сосын кіші әріпке келтіріп салыстырамыз.

def is_palindrome(s):
    i, j = 0, len(s) - 1
    while i < j:
        if not s[i].isalnum():
            i += 1
        elif not s[j].isalnum():
            j -= 1
        else:
            if s[i].lower() != s[j].lower():
                return False
            i += 1
            j -= 1
    return True

Бұл O(n) уақыт пен O(1) қосымша жад. Қысқа нұсқа t = ''.join(c.lower() for c in s if c.isalnum()); t == t[::-1] да O(n), бірақ O(n) жад алады — көп жағдайда бұл да жарайды.

Анаграмма

Екі сөз бір әріптерден құралса, олар анаграмма: «аспан» мен «панас». Тексерудің екі жолы: sorted(a) == sorted(b) (O(n log n)) немесе әріп жиілігін санау Counter(a) == Counter(b) (O(n)). Жиілік санау — келесі сабақтағы hash map-тің алғашқы қолданысы.

Жиі қателер: (1) Цикл ішінде жолды += арқылы ұзарту. (2) Регистрді ескермеу: 'А' != 'а'. (3) s.split(' ') мен s.split() айырмасын ұмыту: соңғысы қатар тұрған бос орындарды бірге өткізеді.

Сабақты интерактивті түрде ашу →

4. Hash map және set: жиілік пен жұптар

dict пен set — hash table. Кілттен hash-функция сан есептейді, сол сан бойынша кілт кестедегі орнына тікелей барады. Сондықтан іздеу, қосу, өшіру — орта есеппен O(1). Тізімде x in a — O(n), set-те x in s — O(1). Кілт hash-талатын (өзгермейтін) болуы керек: str, int, tuple — болады, list — болмайды.

Үлгі 1: жиілік санау

orders = ['Алматы', 'Астана', 'Алматы', 'Шымкент', 'Алматы']
freq = {}
for city in orders:
    freq[city] = freq.get(city, 0) + 1
# {'Алматы': 3, 'Астана': 1, 'Шымкент': 1}

from collections import Counter
Counter(orders).most_common(1)   # [('Алматы', 3)]

Үлгі 2: «бұрын не көрдім?» (two-sum)

Сұрыпталмаған тізімде қосындысы target болатын екі санның индекстерін табу. Әр x үшін бізге target − x керек. Оны бұрын кездестірдік пе — dict-тен O(1)-де сұраймыз:

def two_sum(nums, target):
    pos = {}                       # мән → индекс
    for i, x in enumerate(nums):
        need = target - x
        if need in pos:
            return (pos[need], i)
        pos[x] = i
    return None

two_sum([3000, 7000, 1500, 5500], 7000)   # (2, 3)

Неге pos[x] = i тексеруден кейін? Әйтпесе x + x = target болғанда элементті өзімен жұптап қоямыз. Бұл O(n) уақыт пен O(n) жад; екі цикл O(n²) болар еді.

Үлгі 3: топтау

Кілт ретінде «қолтаңба» алып, соған жататындарды тізімге жинаймыз: мысалы, анаграммаларды топтауда кілт ''.join(sorted(word)). collections.defaultdict(list) бос тізімді өзі жасайды.

Жиі қателер: (1) freq[k] += 1 — кілт әлі жоқ болса KeyError; get(k, 0) немесе Counter қолданыңыз. (2) Тізімді кілт қылу — TypeError: tuple(lst) жасаңыз. (3) set ретсіз екенін ұмыту: «бірінші кездескен» керек болса, тізіммен немесе индекспен жұмыс істеңіз.

5. Stack және queue (deque)

Stack (стек) — «соңғы кірген бірінші шығады» (LIFO): табақтар үйіндісі сияқты, тек үстінен қосып, үстінен аламыз. Python-да стек — кәдімгі list: append(x) салады, pop() алады, st[-1] үстіңгісін көрсетеді — бәрі O(1).

Queue (кезек) — «бірінші кірген бірінші шығады» (FIFO): ЦОН-дағы кезек сияқты. list.pop(0) — O(n), сондықтан collections.deque қолданамыз: append(x) артқа қосады, popleft() алдынан алады — екеуі де O(1).

from collections import deque
q = deque()
q.append('Айгүл'); q.append('Ерлан'); q.append('Дана')
q.popleft()      # 'Айгүл' — бірінші келген бірінші қызмет алады
len(q)           # 2

Мысал: жақшалар балансы

Формулада ( [ { } ] ) жақшалары дұрыс жабылған ба? Ашылған жақшаны стекке саламыз. Жабылатын жақша келгенде стектің үстінде оның жұбы тұруы керек. Соңында стек бос болуы тиіс.

def is_valid(s):
    pairs = {')': '(', ']': '[', '}': '{'}
    st = []
    for ch in s:
        if ch in '([{':
            st.append(ch)
        elif ch in pairs:
            if not st or st.pop() != pairs[ch]:
                return False
    return not st

is_valid('{[()]}')   # True
is_valid('([)]')     # False — ( ашылды, бірақ ] келді

Мысал: жылжымалы терезе кезегі

Колл-орталық соңғы 3 секундтағы (3000 мс) қоңырау санын білгісі келеді. Уақыттары өсу ретімен келеді. Әр жаңа қоңырауды кезекке қосып, алдынан ескіргендерін (t − 3000-нан ертерек) popleft арқылы алып тастаймыз. Әр қоңырау кезекке бір рет кіріп, бір рет шығады — жалпы O(n).

Қайда кездеседі: стек — функция шақырулары (call stack), браузердің «Артқа» батырмасы, undo, өрнекті есептеу, DFS. Кезек — тапсырмалар кезегі (Celery, Kafka), BFS, rate limiting. Жиі қате: бос стектен pop() — IndexError; алдымен if st тексеріңіз.

6. Linked list: байланысқан тізім

Linked list — әр түйін (node) мәнді және келесі түйінге сілтемені сақтайтын тізбек. Массивтен айырмасы: элементтер жадта қатар тұрмайды, сондықтан k-шы элементке жету үшін басынан k қадам жүру керек — O(n). Есесіне басына қосу, белгілі түйіннен кейін кірістіру немесе өшіру — O(1): тек сілтемелерді ауыстырамыз.

class Node:
    def __init__(self, val, next=None):
        self.val = val
        self.next = next

# 1 → 2 → 3
head = Node(1, Node(2, Node(3)))
cur = head
while cur:               # аралау: O(n)
    print(cur.val)
    cur = cur.next

Басына қосуO(n)O(1)

Мысал: тізімді аудару

Классикалық есеп — сілтемелерді кері бағыттау. Үш айнымалы ұстаймыз: prev (аударылған бөліктің басы), cur (қазіргі түйін), nxt (келесісін жоғалтпау үшін).

def reverse_list(head):
    prev = None
    cur = head
    while cur:
        nxt = cur.next     # 1) келесіні сақтаймыз
        cur.next = prev    # 2) сілтемені кері бұрамыз
        prev = cur         # 3) prev алға
        cur = nxt          # 4) cur алға
    return prev            # жаңа бас

Екі жылдамдықты көрсеткіш

Тізімде цикл бар ма (соңғы түйін бұрынғы түйінге сілтейді ме)? Floyd әдісі: slow бір қадам, fast екі қадам жүреді. Цикл болса, олар міндетті түрде кездеседі; болмаса, fast None-ға жетеді. Қосымша жад — O(1). Дәл осы тәсілмен тізімнің ортасын да табады: fast соңына жеткенде, slow ортада.

Шын өмірде: Python-да linked list-ті сирек өзіңіз жазасыз — deque іштей соған ұқсас құрылым. Бірақ сұхбатта (interview) жиі сұралады, және LRU кэш, браузер тарихы сияқты құрылымдардың негізі. Жиі қате: cur.next = prev жасамас бұрын cur.next-ті сақтамау — тізімнің қалғаны жоғалады.

7. Рекурсия және backtracking

Рекурсия — функцияның өзін-өзі шақыруы. Әр рекурсивті функцияда екі бөлік бар: базалық жағдай (бұдан әрі бөлінбейтін, жауабы белгілі кіші есеп) және рекурсивті қадам (есепті кішірек дәл сондай есепке келтіру).

def digit_sum(n):
    if n < 10:                       # базалық жағдай
        return n
    return n % 10 + digit_sum(n // 10)  # соңғы цифр + қалғанының қосындысы

digit_sum(2026)   # 6 + digit_sum(202) = 6 + 2 + digit_sum(20) = … = 10

Әр шақыру call stack-ке жаңа «қабат» қосады. Базалық жағдай жоқ немесе оған жетпесек, стек толады — RecursionError. Python-да тереңдік шегі шамамен 1000, сондықтан 10⁵ тереңдіктегі рекурсия орнына цикл жазамыз.

Backtracking: барлық нұсқаны құру

Backtracking — шешімді қадам-қадаммен құрып, әр қадамда таңдау жасап, тереңге кіріп, сосын таңдауды қайтарып алу. Мысал: Kaspi Red-тағы 3 тауардан {телефон, құлаққап, қап} сатып алудың барлық жиынын тізу. Әр тауар үшін екі таңдау: аламыз / алмаймыз → 2³ = 8 ішкі жиын.

def subsets(items):
    res, cur = [], []
    def go(i):
        if i == len(items):          # барлық тауар бойынша шештік
            res.append(cur[:])       # көшірмесін сақтаймыз!
            return
        cur.append(items[i])         # таңдау: аламыз
        go(i + 1)
        cur.pop()                    # таңдауды қайтарамыз
        go(i + 1)                    # таңдау: алмаймыз
    go(0)
    return res

Ішкі жиын саны 2ⁿ, сондықтан бұл O(n · 2ⁿ) — n = 20 шамасында ғана жарайды. Backtracking-тің күші — кесу (pruning): жарамсыз жолға кірмей тоқтау. Мысалы, жақшалар генерациясында жабылатын жақшаны ашылғандардан көп қоймаймыз.

Жиі қателер: (1) res.append(cur) — көшірме емес, бір тізімге сілтеме; соңында бәрі бос болып шығады. cur[:] жазыңыз. (2) Таңдауды қайтармау (cur.pop()). (3) Базалық жағдайды ұмыту.

8. Binary search: екіге бөліп іздеу

Сұрыпталған тізімнен мән іздеу үшін әр элементті қарау (O(n)) міндетті емес. Binary search ортаңғы элементке қарайды: іздегеніміз одан үлкен болса — оң жартысында, кіші болса — сол жартысында. Әр қадамда іздеу аймағы екі есе кішірейеді, сондықтан 1 000 000 элементте ең көбі ~20 қадам: O(log n).

def binary_search(a, x):
    lo, hi = 0, len(a) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if a[mid] == x:
            return mid
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1

Шекараны іздеу (lower bound)

Көбіне «бар ма?» емес, «x-тен кіші емес бірінші элемент қай жерде?» деген сұрақ қойылады. Мысалы, бағасы бойынша сұрыпталған тауарлардан 15 000 ₸-ден басталатынның біріншісі. Жарты ашық аралықпен [lo, hi) жазу ыңғайлы:

def lower_bound(a, x):
    lo, hi = 0, len(a)
    while lo < hi:
        mid = (lo + hi) // 2
        if a[mid] < x:
            lo = mid + 1
        else:
            hi = mid
    return lo        # барлығы x-тен кіші болса, len(a)

Python-да дайын нұсқасы бар: bisect.bisect_left(a, x) — дәл осы, bisect_right — x-тен үлкен бірінші орын.

Жауап бойынша binary search

Ең күшті қолданысы: жауапты тікелей іздемей, «C мәні жарай ма?» деген тексеру функциясын жазамыз. Егер C жараса, одан үлкендері де жарайтын болса (монотондық), ең кіші жарайтын C-ны binary search-пен табамыз. Мысал: Алматыдан Астанаға жүктерді берілген ретпен D күнде жеткізу керек; күнделікті сыйымдылық кемінде қанша? Сыйымдылық C берілсе, неше күн керегін ашкөз (greedy) түрде O(n)-де санаймыз. Ізделетін аралық: [max(weights), sum(weights)]. Барлығы O(n log S).

Жиі қателер: (1) lo <= hi мен lo < hi-ді, hi = mid мен hi = mid − 1-ді араластыру — шексіз цикл. Бір үлгіні таңдап, соған берік болыңыз. (2) Сұрыпталмаған тізімде binary search қолдану.

9. Сұрыптау: insertion, merge, quick және key

Сұрыптау — көп алгоритмнің бірінші қадамы: сұрыпталған тізімде binary search, екі көрсеткіш, қайталануды табу оңай. Негізгі идеяларды білу маңызды, ал практикада Python-ның sorted / list.sort (Timsort, O(n log n), тұрақты) қолданылады.

Қарапайым O(n²) әдістер

Bubble sort көршілерді салыстырып, үлкенін оңға «көпіршіктетеді». Insertion sort карталарды қолға алғандай: әр жаңа элементті сол жақтағы сұрыпталған бөліктегі орнына кірістіреді. Екеуі де ең нашар жағдайда O(n²), бірақ insertion sort дерлік сұрыпталған тізімде O(n)-ге жақын жұмыс істейді.

Merge sort: бөл де билей бер

def merge_sort(a):
    if len(a) <= 1:
        return a
    mid = len(a) // 2
    left = merge_sort(a[:mid])
    right = merge_sort(a[mid:])
    out, i, j = [], 0, 0
    while i < len(left) and j < len(right):   # екі сұрыпталған тізімді біріктіру
        if left[i] <= right[j]:
            out.append(left[i]); i += 1
        else:
            out.append(right[j]); j += 1
    out.extend(left[i:]); out.extend(right[j:])
    return out

Тізім log n рет екіге бөлінеді, әр деңгейде біріктіру барлығы O(n) — жалпы O(n log n), әрқашан. <= белгісі тең элементтердің бастапқы ретін сақтайды — бұл тұрақтылық (stability).

Quicksort

Тірек элемент (pivot) таңдап, тізімді «кішілер / теңдер / үлкендер» деп бөледі де, бөліктерді рекурсивті сұрыптайды. Орташа O(n log n), бірақ pivot әрдайым ең кіші/үлкен болса (мысалы, сұрыпталған тізімде бірінші элементті алсақ) — O(n²). Сондықтан pivot кездейсоқ таңдалады.

Python-да key арқылы сұрыптау

students = [('Айгерім', 92), ('Бауыржан', 85), ('Әлия', 92), ('Данияр', 78)]
# Ұпай бойынша кемуі, тең болса аты бойынша өсуі
sorted(students, key=lambda r: (-r[1], r[0]))
# [('Айгерім', 92), ('Әлия', 92), ('Бауыржан', 85), ('Данияр', 78)]

Кортеж-кілт бірінші элемент бойынша, тең болса екіншісі бойынша салыстырылады. Сандық өрісті кему ретімен алу үшін алдына минус қоямыз. Ескерту: қазақ әріптерінің Unicode реті әліпбилік ретпен толық сәйкес келмейді ('Ә' кодтары кириллицадан кейін тұр), шын жобада арнайы кілт керек.

Есте сақтаңыз: салыстыруға негізделген кез келген сұрыптау ең нашар жағдайда кемінде ~n log n салыстыру жасайды. Ал мәндер шағын аралықта болса (мысалы, 0–100 ұпай), counting sort O(n + k)-де сұрыптайды.

10. Ағаштар: binary tree және BST

Ағаш (tree) — түйіндер иерархиясы: бір түбір (root), әр түйіннің балалары бар, циклдер жоқ. Файл жүйесі, ұйым құрылымы, HTML DOM — бәрі ағаш. Binary tree-де әр түйінде ең көбі екі бала: left және right.

class TreeNode:
    def __init__(self, val, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

#        8
#       / #      3   10
#     /     #    1   6    14
root = TreeNode(8, TreeNode(3, TreeNode(1), TreeNode(6)), TreeNode(10, None, TreeNode(14)))

Аралау (traversal)

  • Preorder (түбір, сол, оң): 8, 3, 1, 6, 10, 14 — ағашты көшіру үшін.
  • Inorder (сол, түбір, оң): 1, 3, 6, 8, 10, 14 — BST-де сұрыпталған рет береді.
  • Postorder (сол, оң, түбір): 1, 6, 3, 14, 10, 8 — өшіру, қалталар көлемін есептеу.
  • Level order (деңгей-деңгеймен, BFS, deque арқылы): [8], [3, 10], [1, 6, 14].
def height(node):
    if node is None:
        return 0
    return 1 + max(height(node.left), height(node.right))

Binary Search Tree (BST)

BST ережесі: әр түйіннің сол жақ ішкі ағашындағы мәндер одан кіші, оң жағындағылар үлкен. Сонда іздеу binary search сияқты: түбірден бастап, кіші болса солға, үлкен болса оңға жүреміз. Ағаш теңгерілген болса, биіктігі ≈ log n, іздеу мен кірістіру O(log n). Бірақ сұрыпталған мәндерді ретімен кірістірсек, ағаш «тізімге» айналады — биіктік n, операциялар O(n). Сондықтан өндірісте өзін-өзі теңгеретін ағаштар (red-black, AVL, B-tree — дерекқор индекстері) қолданылады.

def bst_insert(node, x):
    if node is None:
        return TreeNode(x)
    if x < node.val:
        node.left = bst_insert(node.left, x)
    elif x > node.val:
        node.right = bst_insert(node.right, x)
    return node            # тең мән қайта қосылмайды
Жиі қателер: (1) None түйінді тексермей node.left-ке жүгіну — AttributeError. (2) Рекурсивті кірістірудің нәтижесін node.left = ... деп сақтамау — жаңа түйін ағашқа ілінбей қалады.

11. Heap және priority queue: top-k

Heap (үйме) — ең кіші (немесе ең үлкен) элементті әрдайым O(1)-де көрсетіп, қосу мен алуды O(log n)-де жасайтын құрылым. Ол «толық» binary tree, бірақ массивте сақталады: i түйінінің балалары — 2i+1 және 2i+2. Ереже: ата-ана балаларынан кіші (min-heap).

Python-да heapq модулі кәдімгі тізімді min-heap ретінде басқарады:

import heapq
h = []
heapq.heappush(h, 5000)
heapq.heappush(h, 1200)
heapq.heappush(h, 3400)
h[0]                 # 1200 — ең кішісі, O(1)
heapq.heappop(h)     # 1200, O(log n)
heapq.heapify(arr)   # тізімді орнында heap-ке айналдыру, O(n)

Max-heap керек болса, мәндерді теріс таңбамен саламыз: heappush(h, -x). Кортеждер де салуға болады: (басымдық, аты) — бірінші элемент бойынша салыстырылады.

Мысал: top-k

Kaspi-дегі 1 000 000 тауардан ең көп сатылған 10-ын табу керек. Бәрін сұрыптау — O(n log n). Жақсырақ: өлшемі k болатын min-heap ұстаймыз. Heap-тің түбірі — «үздік k-ның ең әлсізі». Жаңа сан одан үлкен болса, әлсізін шығарып, жаңасын саламыз. Барлығы O(n log k).

def top_k(nums, k):
    h = []
    for x in nums:
        if len(h) < k:
            heapq.heappush(h, x)
        elif x > h[0]:
            heapq.heapreplace(h, x)   # pop + push бір қадамда
    return sorted(h, reverse=True)

Дайын нұсқасы: heapq.nlargest(k, nums), heapq.nsmallest(k, nums). Heap сонымен қатар Dijkstra алгоритмінде, тапсырмалар жоспарлаушысында, k сұрыпталған тізімді біріктіруде қолданылады.

Жиі қателер: (1) heapq — тек min-heap; max үшін теріс таңба. (2) Heap-тізім толық сұрыпталған емес: h[1] міндетті түрде екінші ең кіші емес. (3) Кортеж салғанда бірінші өрістер тең болса, екіншілері салыстырылады — олар салыстырылмайтын объект болса, қате шығады; арасына реттік нөмір қойыңыз.

12. Графтар: BFS, DFS, ең қысқа жол

Граф — төбелер (vertices) мен оларды қосатын қырлар (edges). Қалалар мен жолдар, әлеуметтік желідегі достар, тәуелділіктер — бәрі граф. Көбіне adjacency list түрінде сақтаймыз: әр төбеге көршілер тізімі. Жады — O(V + E).

roads = [('Алматы', 'Қонаев'), ('Алматы', 'Талдықорған'), ('Қонаев', 'Талдықорған'), ('Астана', 'Қарағанды')]
from collections import defaultdict
adj = defaultdict(list)
for a, b in roads:          # бағытсыз граф: екі жаққа да
    adj[a].append(b)
    adj[b].append(a)

BFS — енінен іздеу

Бастапқы төбеден кезек (deque) арқылы деңгей-деңгеймен тарайды: алдымен 1 қадамдағылар, сосын 2 қадамдағылар… Сондықтан салмақсыз графта BFS ең қысқа жолды (қадам санын) береді. Күрделілігі O(V + E).

from collections import deque
def bfs_dist(adj, start):
    dist = {start: 0}
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if v not in dist:           # әр төбеге бір рет кіреміз
                dist[v] = dist[u] + 1
                q.append(v)
    return dist

DFS — тереңнен іздеу

Бір жолмен мүмкіндігінше тереңге барып, тұйыққа тірелгенде артқа қайтады (стек немесе рекурсия). Байланыс компоненттерін санау, цикл табу, топологиялық сұрыптау үшін қолданылады. Әр төбені visited-ке белгілеуді ұмытпаңыз — әйтпесе циклде шексіз айналасыз.

Тор (grid) — да граф

Қала картасы '.' (жол) және '#' (ғимарат) таңбаларымен берілсе, әр ұяшық — төбе, ал жоғары/төмен/солға/оңға көршілер — қырлар. Курьердің (0, 0)-ден оң жақ төменгі бұрышқа ең аз қадаммен жетуі — BFS есебі. Көршілерді for dr, dc in ((1,0), (-1,0), (0,1), (0,-1)) арқылы аралаймыз, шекарадан шықпауын тексереміз.

Салмақты граф (жол ұзындығы әртүрлі) үшін BFS жарамайды — Dijkstra алгоритмі керек: BFS сияқты, бірақ deque орнына ең жақын төбені беретін heap. Оны «Қиын» есептер жинағында жазасыз.

13. Динамикалық бағдарламалау

Динамикалық бағдарламалау (DP) — есеп бірдей ішкі есептерге бөлінсе және олар қайта-қайта кездессе, әр ішкі есепті бір рет шешіп, жауабын сақтау. Екі жолы бар: memoization (жоғарыдан төмен: рекурсия + кэш) және tabulation (төменнен жоғары: кестені кіші есептерден бастап толтыру).

Мысал 1: баспалдақ

Көктөбеге баратын баспалдақта n саты бар, бір қадамда 1 немесе 2 саты көтерілеміз. Неше тәсіл бар? Соңғы қадам 1 саты болса, оған дейін n−1 сатыға жету тәсілдері; 2 саты болса — n−2. Демек ways(n) = ways(n−1) + ways(n−2).

# Аңғал рекурсия: O(2ⁿ) — ways(40) өте баяу, бір ішкі есеп миллион рет шешіледі
from functools import lru_cache
@lru_cache(maxsize=None)            # memoization: O(n)
def ways(n):
    if n <= 1:
        return 1
    return ways(n - 1) + ways(n - 2)

def ways_tab(n):                    # tabulation: O(n), рекурсиясыз
    a, b = 1, 1                     # ways(0), ways(1)
    for _ in range(n - 1):
        a, b = b, a + b
    return b if n >= 1 else 1

Мысал 2: тиындар (coin change)

Тиындар номиналы берілген, amount теңгені ең аз тиынмен жинау керек. Ашкөз тәсіл (ең үлкен тиыннан бастау) әрдайым дұрыс емес: [1, 3, 4] тиындарымен 6 = 4+1+1 (3 тиын), ал дұрысы 3+3 (2 тиын). DP: dp[x] — x сомасына ең аз тиын. dp[0] = 0, dp[x] = min(dp[x − c] + 1) барлық c ≤ x үшін. Күрделілігі O(amount · тиын саны).

Мысал 3: ең ұзын өспелі ішкі тізбек (LIS)

Теңге бағамының күндік мәндерінен (міндетті түрде қатар емес) қатаң өсетін ең ұзын тізбек. O(n²) DP: dp[i] = 1 + max(dp[j]), j < i және a[j] < a[i]. Жылдамырақ O(n log n) әдіс: tails[k] — ұзындығы k+1 өспелі тізбектердің ең кіші соңғы элементі. Әр жаңа x үшін bisect_left(tails, x) орнын тауып, ауыстырамыз немесе соңына қосамыз; жауап — len(tails).

DP есебін шешу рецепті: (1) күйді анықта (dp[i] нені білдіреді?); (2) өту формуласын жаз; (3) базалық мәндер; (4) толтыру реті; (5) жауап қай ұяшықта. Python-да терең рекурсия шектелген — үлкен n үшін tabulation қауіпсіз.

14. Есептер: Оңай

Бұл сабақ — LeetCode стиліндегі есептер жинағы. Барлығы Оңай деңгейде: бір өту (O(n)), hash map, екі көрсеткіш, prefix sum. Әр есепте функция сигнатурасы берілген; тесттер шеткі жағдайларды (бос тізім, бір элемент, бәрі бірдей) және кейбірінде 100 000 элементтік кірісті тексереді.

Есепті шешу тәртібі

  1. Шартты өз сөзіңізбен айтыңыз. Кіріс не, шығыс не? Мысалдарды қолмен тексеріңіз.
  2. Шеткі жағдайлар: бос кіріс, бір элемент, теріс сандар, қайталанулар.
  3. Алдымен аңғал шешім, оның күрделілігін бағалаңыз. n = 10⁵ болса, O(n²) жарамайды.
  4. Жақсартыңыз: «бұрын не көрдім?» → set/dict; «сұрыпталған» → екі көрсеткіш немесе binary search; «аралық қосындысы» → prefix sum.
  5. Кодтан кейін мысалдарды бойынан өткізіп, «Іске қосу» батырмасымен тексеріңіз.

Prefix sum — бір жаңа құрал

Көп сұрау «l-ден r-ге дейінгі қосынды қанша?» деп сұраса, әр сұрауда цикл жүргізу — O(n) әрқайсысына. Оның орнына бір рет pre[i+1] = pre[i] + a[i] массивін құрамыз; сонда sum(a[l..r]) = pre[r+1] − pre[l] — O(1).

a   = [5, 2, 7, 1]
pre = [0, 5, 7, 14, 15]
# a[1..2] = 2 + 7 = pre[3] - pre[1] = 14 - 5 = 9

15. Есептер: Орташа

Орташа деңгейдегі есептерде бір құрал жетпейді: sliding window, prefix sum + hash map, monotonic stack, топологиялық сұрыптау, торда BFS және 2D DP. Көбінде аңғал O(n²) шешім оңай ойға келеді, бірақ тесттер 10⁵ көлемде тексереді.

Sliding window (жылжымалы терезе)

Ішкі жол/ішкі тізім туралы сұрақтарда (ең ұзын, ең қысқа, шартқа сай) екі көрсеткіш l, r терезені анықтайды. r оңға жылжып, элемент қосады; шарт бұзылса, l оңға жылжып, элемент шығарады. Әр элемент терезеге бір рет кіріп, бір рет шығады — O(n).

# Қайталанбайтын таңбалы ең ұзын ішкі жол
last = {}; l = best = 0
for r, ch in enumerate(s):
    if ch in last and last[ch] >= l:
        l = last[ch] + 1          # терезені қайталанудан кейін бастаймыз
    last[ch] = r
    best = max(best, r - l + 1)

Monotonic stack

«Әр элемент үшін оң жақтағы бірінші үлкенірегі қай жерде?» — стекте әлі жауабы табылмаған индекстерді кему ретімен ұстаймыз. Жаңа элемент стектің үстіндегісінен үлкен болса, соның жауабы — осы элемент; оны шығарамыз. Әр индекс бір рет кіріп, бір рет шығады — O(n).

Топологиялық сұрыптау (Kahn)

Пәндер мен пререквизиттер — бағытталған граф. Кіріс дәрежесі (in-degree) 0 болған пәндерді кезекке саламыз; біреуін алған сайын оның көршілерінің дәрежесін азайтамыз. Барлық пән шықпаса — циклдік тәуелділік бар.

16. Есептер: Қиын

Қиын деңгейдегі есептер бірнеше идеяны біріктіреді және аңғал шешім мүлде жарамайды. Әр есептің астында тексерілген үлгі жатыр — оны танысаңыз, жартысы шешілді.

Monotonic deque

Терезеде максимумды ұстау үшін deque-де индекстерді мәндері кему ретімен сақтаймыз. Жаңа элемент келгенде, одан кіші мәндерді артынан шығарамыз (олар енді ешқашан максимум болмайды). Алдыңғы индекс терезеден шықса, алдынан шығарамыз. Сонда dq[0] — әрдайым терезенің максимумы.

Dijkstra

Салмағы теріс емес графта ең қысқа жол: heap-те (қашықтық, төбе). Ең жақын төбені алып, көршілерін «босаңсытамыз» (relax): d + w < dist[v] болса, жаңартып heap-ке саламыз. Heap-тен алынған ескірген жазбаларды (d > dist[u]) өткізіп жібереміз.

dist = [INF] * n; dist[src] = 0
h = [(0, src)]
while h:
    d, u = heapq.heappop(h)
    if d > dist[u]:
        continue
    for v, w in adj[u]:
        if d + w < dist[v]:
            dist[v] = d + w
            heapq.heappush(h, (dist[v], v))
Кеңес: алдымен шағын мысалды қағазда қадамдап жүріп шығыңыз. Қиын есептердегі қателердің көбі — шекаралар: бос кіріс, k = 1, барлық мән бірдей, жету мүмкін емес төбе.
