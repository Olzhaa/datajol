JV1 Java: Java қазақша: синтаксис, класстар, коллекциялар, exceptions, браузерде код жазу

Java тілінің негіздері: main және println, типтер, String пен StringBuilder, шарттар мен циклдер, әдістер, массивтер, класс пен объект, мұрагерлік пен interface, коллекциялар, exception, generics, lambda мен stream, рекурсия. Әр сабақта толық Java бағдарламасын өзіңіз жазып, тестпен тексересіз, соңында екі есептер жинағы мен емтихан бар.

Тапсырмаларды орындау

1. Java-мен танысу: main, println және Scanner

Java — 1995 жылдан бері қолданылып келе жатқан, қатаң типтелген, объектіге бағытталған тіл. Онда Android қосымшалары, банктердің backend жүйелері, сондай-ақ дата-инженерияның «ауыр» құралдары (Apache Spark, Kafka, Hadoop) жазылған. Сондықтан деректермен жұмыс істейтін маман Java кодын оқи алса, үлкен артықшылық.

Компиляция және JVM

Python кодты жолма-жол орындайды. Java басқаша: алдымен javac компиляторы Main.java файлын bytecode-қа (Main.class) аударады, содан кейін JVM (Java Virtual Machine) сол bytecode-ты орындайды. JVM Windows-та да, Linux-та да, Mac-та да бар, сондықтан бір рет компиляцияланған код барлық жерде жүреді — «write once, run anywhere». Компилятор көп қатені іске қоспай тұрып-ақ табады: типтің сәйкес келмеуі, нүктелі үтірдің ұмытылуы, жоқ айнымалы.

Ең кіші бағдарлама

public class Main {
    public static void main(String[] args) {
        System.out.println("Salem, Almaty!");   // жаңа жолмен басып шығарады
        System.out.print("Bir ");                // жаңа жолсыз
        System.out.print("jol");
    }
}

Әр бөлігі не істейді: public class Main — бағдарлама класс ішінде өмір сүреді, файл аты класс атымен бірдей болуы керек. public static void main(String[] args) — кіру нүктесі, JVM орындауды осы жерден бастайды. Әр нұсқаулық ; белгісімен аяқталады, блоктар { } ішінде жазылады, ал үлкен-кіші әріп маңызды: Main мен main — екі бөлек нәрсе. Түсініктеме // немесе /* ... */ арқылы жазылады.

Кірісті оқу: Scanner

import java.util.Scanner;

public class Main {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        String name = sc.next();    // бір сөз (бос орынға дейін)
        int age = sc.nextInt();     // бүтін сан
        System.out.println(name + " " + (age + 1));
    }
}

Кіріс Aruzhan 19 болса, бағдарлама Aruzhan 20 басады. Жолдар + арқылы біріктіріледі, ал (age + 1) жақшасы алдымен санды қосу үшін керек.

Бұл платформада әр тапсырма — толық бағдарлама. Тест бағдарламаға stdin арқылы кіріс береді де, stdout-қа шыққан мәтінді күтілген жауаппен салыстырады. Сондықтан артық мәтін («Санды енгізіңіз:») басып шығармаңыз.

2. Типтер, айнымалылар және арифметика

Java — статикалық типтелген тіл: әр айнымалының типі компиляция кезінде белгілі және кейін өзгермейді. int count = 5; жазғаннан кейін count = "бес"; деп жаза алмайсыз — компилятор қате береді. Бұл қателерді ерте ұстауға көмектеседі.

Primitive типтер

ТипӨлшеміМысал
int32 бит, ±2.1 млрдint qty = 3;
long64 бит, ±9.2·10¹⁸long revenue = 5_000_000_000L;
double64 бит, бөлшек санdouble rate = 0.12;
charбір символchar grade = 'A';
booleantrue / falseboolean paid = true;

Сондай-ақ byte, short, float бар, бірақ күнделікті кодта сирек қолданылады. String — primitive емес, ол класс (reference type), бірақ өте жиі кездеседі. var x = 10; деп жазсаңыз, компилятор типті өзі анықтайды (мұнда int), бірақ тип бәрібір тұрақты.

Бүтін санды бөлу және қалдық

int total = 1000, people = 3;
System.out.println(total / people);            // 333  — бөлшек бөлігі тасталады
System.out.println(total % people);            // 1    — қалдық
System.out.println((double) total / people);   // 333.3333333333333
System.out.println(String.format("%.2f", (double) total / people)); // 333.33

Екі int-ті бөлсеңіз, нәтиже де int болады. Бөлшек нәтиже керек болса, бір операндты (double) арқылы түрлендіресіз (casting). Ал double avg = total / people; жазсаңыз, алдымен бүтін бөлу орындалады (333), кейін ғана 333.0-ге айналады — жиі кездесетін қате.

Overflow

int-тің шегі — 2 147 483 647. Одан асып кетсе, Java қате бермейді, сан «айналып» теріс болып шығады. Айлық айналым теңгемен миллиардтарға жетсе, long қолданыңыз. Өзгермейтін мәндер үшін final: final double VAT = 0.12;.

Ақша сомасын double-да сақтау тәуекелді: 0.1 + 0.2 дәл 0.3 емес. Нақты банк жүйелерінде тиынмен long немесе BigDecimal қолданылады.

3. String және StringBuilder

String — Java-дағы ең жиі қолданылатын класс. Оның басты қасиеті: immutable, яғни құрылған жолды өзгерту мүмкін емес. s.toUpperCase() жаңа жол қайтарады, ал s бұрынғыдай қалады.

Негізгі әдістер

String city = "Shymkent";
city.length()            // 8
city.charAt(0)           // 'S'  (индекс 0-ден басталады)
city.substring(1, 4)     // "hym" (1-ден 4-ке дейін, 4 кірмейді)
city.indexOf("ken")      // 4, табылмаса -1
city.toLowerCase()       // "shymkent"
city.contains("kent")    // true
"  hi ".trim()           // "hi"
"a,b,c".split(",")       // ["a", "b", "c"] массиві

== емес, equals

== екі айнымалы бір объектіге сілтейтінін тексереді, ал мазмұнды салыстыру үшін equals керек. Scanner-ден оқылған "yes" мен кодтағы "yes" литералы әртүрлі объект болуы мүмкін, сондықтан answer == "yes" кейде false береді. Әрқашан answer.equals("yes") немесе equalsIgnoreCase жазыңыз. Әліпби бойынша салыстыру — a.compareTo(b): теріс, нөл немесе оң сан қайтарады.

StringBuilder

String immutable болғандықтан, циклде s = s + x жазу әр қадамда жаңа жол жасап, барлық символдарды көшіреді — n қадамда O(n²). StringBuilder — өзгермелі буфер:

StringBuilder sb = new StringBuilder();
for (int i = 1; i <= 5; i++) {
    sb.append(i).append(' ');
}
System.out.println(sb.toString().trim());   // 1 2 3 4 5
System.out.println(new StringBuilder("kaspi").reverse()); // ipsak

append кез келген типті қабылдайды, reverse() жолды аударады, insert, deleteCharAt, setCharAt те бар. Соңында toString() арқылы кәдімгі String аласыз.

char мен String әртүрлі: 'a' — символ (бір тырнақша), "a" — жол (қос тырнақша). s.charAt(i) == 'x' дұрыс, себебі char — primitive.

4. Шарттар: if, else және switch

Шарт boolean мәнге негізделеді. Салыстыру операторлары: == != < > <= >=. Логикалық операторлар: && (және), || (немесе), ! (емес). && мен || «қысқа тұйықталады»: x != 0 && 10 / x > 2 жазбасында x нөл болса, екінші бөлігі мүлдем есептелмейді.

if / else if / else

int tenge = 25000;
if (tenge >= 50000) {
    System.out.println("Free delivery");
} else if (tenge >= 20000) {
    System.out.println("Delivery 500");
} else {
    System.out.println("Delivery 1500");
}
String status = tenge > 0 ? "paid" : "empty";   // ternary оператор

Шарттар жоғарыдан төмен тексеріледі, біріншісі орындалса, қалғандары өткізіп жіберіледі. Сондықтан үлкен шекті бірінші жазамыз. Блокта бір ғана жол болса да, фигуралық жақшаны қалдырмаған дұрыс — кейін жол қосқанда қате жібермейсіз.

Классикалық switch

switch (day) {
    case 6:
    case 7:
        System.out.println("Weekend");
        break;
    default:
        System.out.println("Workday");
}

Классикалық switch-те break болмаса, орындау келесі case-ке «құлап түседі» (fall-through). Кейде бұл әдейі қолданылады (6 мен 7 бірге), бірақ көбіне қате.

Жаңа switch (Java 14+)

String name = switch (day) {
    case 1, 2, 3, 4, 5 -> "Workday";
    case 6, 7 -> "Weekend";
    default -> "Unknown";
};

Жебелі (->) түрінде fall-through жоқ, ал switch өзі мән қайтарады. switch int, char, String және enum мәндерімен жұмыс істейді.

Кібісе жыл ережесі шарттарды біріктіруге жақсы мысал: 4-ке бөлінеді, бірақ 100-ге бөлінбейді, НЕМЕСЕ 400-ге бөлінеді. Бір шарт: (y % 4 == 0 && y % 100 != 0) || y % 400 == 0.

5. Циклдер: for, while, break және continue

Цикл бір әрекетті бірнеше рет қайталайды. Java-да үш негізгі түрі бар.

for

for (int i = 1; i <= 5; i++) {
    System.out.print(i + " ");      // 1 2 3 4 5
}

Жақша ішінде үш бөлік: бастапқы мән, жалғастыру шарты, әр қадамнан кейінгі өзгеріс. i айнымалысы тек цикл ішінде көрінеді. Ең жиі қате — off-by-one: < мен <= шатастыру. n элементті массивті аралағанда i = 0; i < n жазылады.

while және do-while

Қанша рет қайталанатыны алдын ала белгісіз болса, while ыңғайлы. Мысал: депозитке 500 000 теңге салдық, жылдық 12%. Неше жылда 1 000 000-нан асады?

double money = 500000;
int years = 0;
while (money < 1000000) {
    money = money * 1.12;
    years++;
}
System.out.println(years);   // 7

do { ... } while (cond); денесін кемінде бір рет орындайды, шартты соңынан тексереді. Мысалы, санның цифрларын санағанда 0 санының өзі бір цифр болуы керек — do-while дәл осыған лайық.

break және continue

break циклді толық тоқтатады, continue ағымдағы қадамның қалғанын өткізіп, келесі қадамға өтеді. Кірістірілген циклдерде break тек ішкі циклден шығады.

for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;   // жұп сандарды өткізіп жіберу
    if (i > 7) break;           // 7-ден кейін тоқтау
    System.out.print(i + " ");  // 1 3 5 7
}

Цифрлармен жұмыс

n % 10 — соңғы цифр, n / 10 — соңғы цифрсыз сан. Осы екеуін while (n > 0) циклінде қайталасаңыз, санның барлық цифрын оңнан солға қарай аласыз.

Цикл шарты ешқашан false болмаса, бағдарлама мәңгі айналады (infinite loop) және тест уақыт шегінен асады. while жазғанда шартқа әсер ететін айнымалы денеде өзгеретініне көз жеткізіңіз.

6. Әдістер (methods) және overloading

Әдіс (method) — атауы бар, қайта қолданылатын код бөлігі. Python-дағы функцияның баламасы, бірақ Java-да әр әдіс класс ішінде тұрады. Әзірге объектсіз шақырылатын static әдістерді жазамыз.

public class Main {
    static long withVat(long price) {        // қайтару типі, аты, параметрлері
        return price + price * 12 / 100;
    }

    static void printReceipt(String item, long price) {   // void — ештеңе қайтармайды
        System.out.println(item + ": " + withVat(price));
    }

    public static void main(String[] args) {
        printReceipt("Phone", 250000);   // Phone: 280000
    }
}

Әдістің сигнатурасы — аты және параметр типтері. Қайтару типі жазылуы міндетті; void емес әдістің барлық жолы return-мен аяқталуы керек, әйтпесе компилятор қате береді.

Overloading

Бір атпен, бірақ параметрлері әртүрлі бірнеше әдіс жазуға болады:

static int area(int side) { return side * side; }
static int area(int w, int h) { return w * h; }
static double area(double r) { return Math.PI * r * r; }

Компилятор аргументтердің саны мен типіне қарап, қайсысын шақыру керегін өзі таңдайды. Тек қайтару типі әртүрлі екі әдіс (int f(int) және double f(int)) қатар тұра алмайды — шақыру кезінде оларды ажырату мүмкін емес.

Pass-by-value

Java аргументтерді әрқашан мәні бойынша береді. Primitive (int, double) берілсе, әдіс оның көшірмесін алады: ішінде өзгерткеніңіз сыртқа әсер етпейді. Массив не объект берілсе, сілтеменің көшірмесі беріледі — екі сілтеме бір объектіге қарайды, сондықтан arr[0] = 5 сыртта да көрінеді. Ал arr = new int[3] деп сілтемені ауыстырсаңыз, сыртқы айнымалы өзгермейді.

Жақсы әдіс бір ғана нәрсе жасайды және атауы соны айтады: isPrime, gcd, parsePrice. boolean қайтаратын әдістер әдетте is/has сөзімен басталады.

7. Массивтер және 2D массивтер

Массив — бір типтегі, өлшемі тұрақты элементтер тізбегі. Құрылғаннан кейін ұзындығын өзгерту мүмкін емес (ол үшін келесі сабақтардағы ArrayList бар).

int[] sales = new int[5];            // [0, 0, 0, 0, 0]
int[] prices = {1200, 800, 4500};    // мәндерімен бірге
System.out.println(prices.length);   // 3 (жақшасыз — бұл өріс)
prices[1] = 950;
for (int p : prices) {               // enhanced for: тек оқу үшін ыңғайлы
    System.out.print(p + " ");
}

new арқылы жасалған массив әдепкі мәндермен толады: сандар үшін 0 / 0.0, boolean үшін false, объектілер (String) үшін null. Индекстер 0-ден length - 1-ге дейін. Стандарт JVM-де шектен тыс индекс ArrayIndexOutOfBoundsException лақтырады, сондықтан цикл шекарасын әрқашан мұқият жазыңыз.

Пайдалы құралдар

import java.util.Arrays;
Arrays.sort(prices);                         // орнында сұрыптау
System.out.println(Arrays.toString(prices)); // [800, 1200, 4500]
int[] copy = Arrays.copyOf(prices, prices.length);
int[] same = prices;   // көшірме ЕМЕС: бір массивке екі сілтеме

Ең үлкен және ең кіші мән

Максимумды іздегенде бастапқы мәнді 0 деп алу — классикалық қате: барлық сан теріс болса, жауап 0 болып шығады. Бастапқы мән ретінде бірінші элементті (a[0]) немесе Integer.MIN_VALUE алыңыз.

2D массивтер

Кесте, карта торы, матрица — массивтер массиві:

int[][] grid = new int[3][4];      // 3 жол, 4 баған
grid[1][2] = 7;
int rows = grid.length;            // 3
int cols = grid[0].length;         // 4
for (int r = 0; r < rows; r++) {
    for (int c = 0; c < cols; c++) {
        System.out.print(grid[r][c] + " ");
    }
    System.out.println();
}

Әр жолдың ұзындығы әртүрлі болуы мүмкін (jagged array): int[][] t = new int[3][]; да t[0] = new int[5];. Матрицаны транспонирлеу (жол ↔ баған) — t[c][r] = m[r][c], нәтиженің өлшемі cols × rows.

Scanner-мен массив оқу үлгісі: алдымен n = sc.nextInt(), сосын for ішінде a[i] = sc.nextInt(). Сандардың жолдарға қалай бөлінгені маңызды емес — nextInt бос орын мен жаңа жолды бірдей өткізеді.

8. Класс пен объект: constructor және encapsulation

Класс — үлгі (сызба), объект — сол үлгі бойынша жасалған нақты дана. Мысалы, Product класында аты мен бағасы бар, ал «iPhone, 450 000 ₸» — оның бір объектісі. Класс деректерді (өрістер, fields) және оларға қатысты әрекеттерді (әдістер) бір жерге жинайды.

class Product {
    private String name;          // өрістер
    private int price;

    Product(String name, int price) {   // constructor
        this.name = name;               // this.name — өріс, name — параметр
        this.price = price;
    }

    int getPrice() { return price; }    // getter

    void applyDiscount(int percent) {
        if (percent < 0 || percent > 90) return;   // ережені класс өзі қорғайды
        price = price - price * percent / 100;
    }

    public String toString() { return name + " (" + price + ")"; }
}

Product p = new Product("iPhone", 450000);
p.applyDiscount(10);
System.out.println(p);    // iPhone (405000)

Constructor

Constructor — класс атымен аталатын, қайтару типі жоқ ерекше әдіс. new шақырылғанда объектіні бастапқы күйге келтіреді. Бірнеше constructor жазуға болады (overloading), ал біреуі екіншісін this(...) арқылы шақыра алады. Ешбір constructor жазбасаңыз, компилятор бос constructor-ды өзі қосады.

Encapsulation

Өрістерді private етіп, оларға тек әдістер арқылы қол жеткізу — инкапсуляция. Сонда баға теріс болып кетпейді, себебі оны өзгертудің жалғыз жолы — тексеру жасайтын әдіс. Қол жеткізу деңгейлері: private (тек осы класс), әдепкі (бір package), protected (package + ұрпақтар), public (барлығы).

static өрістер

static өріс жеке объектіге емес, бүкіл класқа тиесілі: барлық объект бір мәнді бөліседі. Мысалы, static int created — неше объект жасалғанының санауышы. static әдіс this-ті көрмейді, сондықтан объект өрістеріне тікелей қол жеткізе алмайды.

Бұл платформада бірнеше класты бір файлға жазуға болады: public class Main біреу ғана, ал қосымша кластар public-сіз (class Account { ... }) Main-нен кейін не алдында тұрады.

9. Мұрагерлік, полиморфизм және interface

Мұрагерлік (inheritance) бар класты кеңейтіп, жаңа класс жасауға мүмкіндік береді: class Dog extends Animal. Dog Animal-дың өрістері мен әдістерін алады және өзінікін қоса алады. Java-да класс тек бір класты extends ете алады.

abstract class Employee {
    protected String name;
    Employee(String name) { this.name = name; }
    abstract long monthlyPay();               // денесі жоқ: ұрпақтар міндетті түрде жазады
    String describe() { return name + ": " + monthlyPay(); }
}

class Salaried extends Employee {
    private long salary;
    Salaried(String name, long salary) {
        super(name);                           // ата-класс constructor-ы
        this.salary = salary;
    }
    @Override
    long monthlyPay() { return salary; }
}

class Hourly extends Employee {
    private long rate, hours;
    Hourly(String name, long rate, long hours) { super(name); this.rate = rate; this.hours = hours; }
    @Override
    long monthlyPay() { return rate * hours; }
}

abstract класстан тікелей объект жасалмайды. @Override аннотациясы компиляторға «мен ата-кластың әдісін қайта жазып жатырмын» дейді: атауда қате болса, бірден ескертеді.

Полиморфизм

Employee[] staff = { new Salaried("Aliya", 600000), new Hourly("Timur", 3000, 120) };
for (Employee e : staff) {
    System.out.println(e.describe());   // әрқайсысы өз monthlyPay()-ін шақырады
}

Айнымалы типі Employee болса да, қай әдіс шақырылатынын объектінің нақты типі анықтайды (dynamic dispatch). Осының арқасында жаңа қызметкер түрін қосқанда циклді өзгертудің қажеті жоқ.

Interface

Interface — «келісім-шарт»: класс қандай әдістерге ие болуы керегін айтады, бірақ күй (өріс) сақтамайды. Класс бірнеше interface-ті implements ете алады.

interface Shape {
    double area();
    default String label() { return "shape"; }   // default әдіс: дайын денесі бар
}
class Square implements Shape {
    private double s;
    Square(double s) { this.s = s; }
    public double area() { return s * s; }        // interface әдістері public
}
Қашан не таңдау керек: ортақ өріс пен кодты бөлісетін туыс кластар — abstract class; «осы әрекетті істей алады» деген қабілет (Comparable, Runnable, Shape) — interface. Барлық класс Object-тен мұра алады, сондықтан toString, equals, hashCode әрқайсысында бар.

10. Коллекциялар: ArrayList, HashMap, HashSet

Массивтің өлшемі тұрақты, ал нақты деректер өседі. Java Collections Framework дайын құрылымдар береді. Ең жиі қолданылатын үшеуі:

InterfaceІске асыруНе үшін
ListArrayListреті бар, индекспен қол жеткізу, қайталану болады
MapHashMap, TreeMapкілт → мән, кілт бойынша O(1) іздеу

import java.util.*;

List<String> cities = new ArrayList<>();
cities.add("Almaty"); cities.add("Astana");
cities.get(0);          // "Almaty"
cities.size();          // 2

    System.out.println(e.getKey() + " " + e.getValue());

Set<Integer> seen = new HashSet<>();

seen.size();           // 1

Generics және wrapper кластар

Бұрыштық жақшадағы тип (<String>) коллекцияда не сақталатынын айтады — компилятор басқа типті қосуға жол бермейді. Коллекциялар тек объект сақтайды, сондықтан primitive орнына wrapper класс жазылады: int → Integer, double → Double, char → Character. List<int> — компиляция қатесі. Java мәндерді автоматты түрде орап-ашады (autoboxing). Бірақ абай болыңыз: екі Integer-ді == арқылы салыстыру 127-ден үлкен мәндерде false беруі мүмкін — equals қолданыңыз.

Реті

HashMap мен HashSet элементтерді белгілі бір ретпен сақтауға кепілдік бермейді. Кілттер әліпби бойынша керек болса — TreeMap/TreeSet (O(log n)), қосылу реті керек болса — LinkedHashMap.

Айнымалыны interface типімен жариялау дағдысы: List<String> xs = new ArrayList<>();. Кейін іске асыруды ауыстыру (мысалы, LinkedList-ке) бір сөзді өзгертумен шешіледі.

11. Exceptions: try, catch, throw және өз exception-ыңыз

Exception — бағдарламаның қалыпты ағынын бұзатын оқиға: санға айналмайтын жол, жоқ файл, null сілтеме. Exception лақтырылғанда (throw), Java шақыру стегі бойынша жоғары қарай оны ұстайтын (catch) блокты іздейді. Ешкім ұстамаса, бағдарлама stack trace басып тоқтайды.

try {
    int qty = Integer.parseInt("12a");     // NumberFormatException
    System.out.println("never printed");
} catch (NumberFormatException e) {
    System.out.println("Bad number: " + e.getMessage());
} finally {
    System.out.println("always");          // қате болса да, болмаса да орындалады
}

Бірнеше catch жазуға болады — алдымен нақтырақ тип, сосын жалпысы. Бір блокта бірнеше тип: catch (IllegalArgumentException | IllegalStateException e). finally ресурстарды жабуға арналған; заманауи кодта оның орнына try-with-resources қолданылады: try (Scanner sc = new Scanner(file)) { ... } — ресурс өзі жабылады.

Checked және unchecked

Checked exception-дар (IOException, Exception-нің RuntimeException емес ұрпақтары) — сыртқы әлемдегі күтуге болатын ақаулар. Компилятор оларды не catch етуді, не әдіс сигнатурасында throws арқылы жариялауды талап етеді. Unchecked (RuntimeException ұрпақтары: NullPointerException, IllegalArgumentException, NumberFormatException, ArithmeticException, ArrayIndexOutOfBoundsException) — әдетте код қатесі, оларды жариялау міндетті емес.

throw және өз exception класыңыз

class InsufficientFundsException extends Exception {
    InsufficientFundsException(String message) { super(message); }
}

void withdraw(long amount) throws InsufficientFundsException {
    if (amount <= 0) throw new IllegalArgumentException("Bad amount: " + amount);
    if (amount > balance)
        throw new InsufficientFundsException("Not enough: need " + amount + ", have " + balance);
    balance -= amount;
}

Өз exception-ыңыз доменнің тілінде сөйлейді: шақырушы catch (InsufficientFundsException e) деп нақты жағдайды өңдейді. super(message) хабарламаны сақтайды, ол e.getMessage() арқылы оқылады.

Exception-ды үнсіз жұтпаңыз: бос catch (Exception e) {} қатені жасырады. Тым жалпы catch (Exception e) орнына күтетін нақты типті ұстаңыз.

12. Generics, lambda және stream

Generics бір кодты әртүрлі типтермен қауіпсіз қолдануға мүмкіндік береді. ArrayList<String> қолданғанда сіз generic класты пайдаланып отырсыз; енді өзіңіз жазайық:

class Pair<A, B> {
    private final A first;
    private final B second;
    Pair(A first, B second) { this.first = first; this.second = second; }
    A getFirst() { return first; }
    B getSecond() { return second; }
}
Pair<String, Integer> p = new Pair<>("Almaty", 2_200_000);

static <T extends Comparable<T>> T maxOf(List<T> xs) {   // generic әдіс
    T best = xs.get(0);
    for (T x : xs) if (x.compareTo(best) > 0) best = x;
    return best;
}

T extends Comparable<T> — шектеу (bound): T салыстыруға келетін тип болуы керек. Generics тек компиляция кезінде тексеріледі; іске қосылғанда тип туралы ақпарат өшіріледі (type erasure), сондықтан new T() жазуға болмайды.

Lambda

Lambda — бір әдісі бар interface-тің (functional interface) қысқа жазбасы: (параметрлер) -> өрнек.

Predicate<Integer> isBig = x -> x > 100000;        // boolean test(x)
Function<String, Integer> len = s -> s.length();      // R apply(x)
Comparator<Student> byScore = (a, b) -> b.score - a.score;   // кему бойынша

students.sort((a, b) -> {
    if (a.score != b.score) return b.score - a.score;  // алдымен балл кемуі
    return a.name.compareTo(b.name);                   // тең болса, аты бойынша
});

Comparator теріс сан қайтарса, a алдында тұрады, оң болса — b. Method reference — lambda-ның тағы да қысқа түрі: String::length, Integer::sum.

Stream

Stream — коллекцияны «конвейер» арқылы өңдеу: filter → map → нәтиже. Бастапқы коллекция өзгермейді.

int[] prices = {1200, 45000, 800, 150000, 45000};
long expensive = Arrays.stream(prices).filter(p -> p > 10000).count();        // 3
int total = Arrays.stream(prices).sum();
int[] uniq = Arrays.stream(prices).distinct().sorted().toArray();           // [800, 1200, 45000, 150000]
List<String> names = students.stream()
    .filter(s -> s.score >= 90)
    .map(s -> s.name)
    .collect(Collectors.toList());
Stream оқуға ыңғайлы, бірақ кез келген циклді stream-ге айналдырудың қажеті жоқ. Қарапайым әрі жылдам цикл көбіне түсініктірек. Ал Spark-тың Java/Scala API-і дәл осы filter/map стилінде жазылады.

13. Scanner тереңірек және рекурсия

Scanner: next, nextInt, nextLine

next() мен nextInt() бос орындарды (пробел, жаңа жол) өткізіп, келесі таңбалауышты (token) оқиды. nextLine() ағымдағы жолдың қалғанын оқиды. Осыдан белгілі қақпан шығады:

// Кіріс:
// 3
// Almaty Astana Shymkent
int n = sc.nextInt();        // 3 оқылды, курсор "3"-тен кейін, жол соңында тұр
String line = sc.nextLine(); // "" — бірінші жолдың қалғаны (бос)!
line = sc.nextLine();        // "Almaty Astana Shymkent"

Шешімі: nextInt-тен кейін бір «бос» nextLine() шақыру, не барлығын token бойынша оқу. Санның қанша екені белгісіз болса, hasNextInt() қолданылады — ол келесі token бүтін сан ба, соны тексереді, кіріс біткенде немесе сан емес token кездескенде false қайтарады:

long sum = 0;
while (sc.hasNextInt()) {
    sum += sc.nextInt();
}

Рекурсия

Рекурсия — әдістің өзін-өзі шақыруы. Әр рекурсивті әдісте екі бөлік бар: базалық жағдай (тоқтау шарты) және есепті кішірейтетін рекурсивті қадам.

static long factorial(int n) {
    if (n <= 1) return 1;            // базалық жағдай
    return n * factorial(n - 1);     // кішірек есеп
}

Әр шақыру call stack-ке жаңа фрейм қосады. Базалық жағдай ұмытылса немесе тереңдік тым үлкен болса, StackOverflowError пайда болады. Наивті Fibonacci fib(n) = fib(n-1) + fib(n-2) бір мәнді қайта-қайта есептейді, шақырулар саны экспоненциалды өседі; есептелген мәндерді массивте сақтау (memoization) оны O(n) етеді.

Backtracking

Рекурсия «барлық нұсқаны тексеру» есептеріне табиғи сәйкес келеді: әр қадамда таңдау жасаймыз, рекурсияға түсеміз, сосын таңдауды кері қайтарамыз. Мысалы, ұзындығы n екілік жолдарды құрастыру:

static void gen(StringBuilder cur, int n) {
    if (cur.length() == n) { System.out.println(cur); return; }
    for (char c : new char[]{'0', '1'}) {
        cur.append(c);                      // таңдау
        gen(cur, n);                        // тереңдеу
        cur.deleteCharAt(cur.length() - 1); // кері қайтару
    }
}
Рекурсия жазбас бұрын екі сұраққа жауап беріңіз: «ең кіші кіріс қандай және оның жауабы не?» және «n үшін жауапты n−1 (немесе n/2) жауабы арқылы қалай аламын?».

14. Есептер жинағы 1: Оңай → Орташа

Бұл сабақта жаңа тақырып жоқ: бұрын үйренгеніңізді DSA-стильді есептерде қолданасыз. Есептер оңайдан орташаға қарай орналасқан. Әрқайсысын шешпес бұрын үш нәрсе жасаңыз:

  • Кіріс пішімін анықтаңыз: алдымен не келеді (n, сосын массив?), қандай типпен оқу керек.
  • Шеткі жағдайларды ойлаңыз: бір элемент, бәрі бірдей, жауап жоқ.
  • Күрделілікті бағалаңыз: n = 10⁵ болса, O(n²) тым баяу — HashMap/HashSet O(n) береді.

Пайдалы үлгілер

// жиілік санау (тек кіші латын әріптері)
int[] cnt = new int[26];
for (char c : s.toCharArray()) cnt[c - 'a']++;

// "бұрын көрдім бе?" + индекс
Map<Integer, Integer> pos = new HashMap<>();
if (pos.containsKey(need)) { ... }
pos.putIfAbsent(x, i);

// екі көрсеткіш (two pointers)
int i = 0, j = s.length() - 1;
while (i < j) { ...; i++; j--; }

c - 'a' трюгі: char Java-да сан ретінде де жұмыс істейді, 'c' - 'a' == 2. Сондықтан 26 ұяшықты массив кіші латын әріптерінің жиілігін HashMap-тен жылдамырақ санайды. Character.toLowerCase(c) регистрді біріздендіреді.

Two Sum есебіндегі негізгі идея: әр a[j] үшін «маған target − a[j] керек, ол бұрын кездесті ме?» деп HashMap-тен сұраймыз. Бұл O(n²) жұп іздеуді O(n)-ге түсіреді — сұхбаттарда ең жиі сұралатын трюктердің бірі.

Шығыс пішіміне мұқият болыңыз: тест мәтінді дәл салыстырады. YES мен Yes — әртүрлі жауап.

15. Есептер жинағы 2: Орташа → Қиын

Екінші жинақтағы есептер деректер құрылымын дұрыс таңдауды талап етеді. Java-да олардың бәрі дайын тұр:

ҚұрылымJava класыНегізгі әдістер
StackArrayDeque<Character>push, pop, peek, isEmpty
QueueArrayDeque<int[]>offer, poll, isEmpty
Sliding windowHashMap / int[128]соңғы көрінген индекс
DP кестесіint[], int[][]Arrays.fill

Ескі Stack класының орнына ArrayDeque ұсынылады: ол жылдамырақ және stack те, queue де бола алады.

BFS үлгісі

int[][] dist = new int[r][c];
for (int[] row : dist) Arrays.fill(row, -1);
ArrayDeque<int[]> q = new ArrayDeque<>();
q.offer(new int[]{0, 0});
dist[0][0] = 0;
int[] dr = {1, -1, 0, 0}, dc = {0, 0, 1, -1};
while (!q.isEmpty()) {
    int[] cur = q.poll();
    for (int k = 0; k < 4; k++) {
        int nr = cur[0] + dr[k], nc = cur[1] + dc[k];
        if (nr < 0 || nr >= r || nc < 0 || nc >= c) continue;   // шекараны ӘРҚАШАН тексеріңіз
        if (grid[nr].charAt(nc) == '#' || dist[nr][nc] != -1) continue;
        dist[nr][nc] = dist[cur[0]][cur[1]] + 1;
        q.offer(new int[]{nr, nc});
    }
}

BFS салмақсыз торда ең қысқа жолды береді, себебі ол ұяшықтарды қашықтық ретімен ашады. Күрделілігі O(R·C).

Динамикалық бағдарламалау

Coin change есебінде dp[x] — x соманы жинайтын ең аз монета саны. dp[0] = 0, қалғаны «шексіздік», ал әр x үшін dp[x] = min(dp[x − coin] + 1). Greedy тәсіл (әр қадамда ең үлкен монетаны алу) әрқашан дұрыс емес: {1, 5, 10, 21} монеталарымен 30 соманы greedy 21 + 5 + 1 + 1 + 1 + 1 = 6 монетамен жинайды, ал оптимум 10 + 10 + 10 = 3 монета.

Binary search-те ортасын mid = lo + (hi - lo) / 2 деп есептеңіз: (lo + hi) / 2 үлкен индекстерде int overflow береді.
