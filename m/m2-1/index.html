M2.1 Python Fundamentals: Python негіздері қазақша

Python — data маманының негізгі тілі. Мұнда кодты браузерде жазып, бірден іске қосасыз. Бірінші іске қосу Python ортасын жүктейді (шамамен 10 МБ), сосын жылдам жұмыс істейді.

Тапсырмаларды орындау

1. print және бірінші бағдарлама

Python бағдарламасы — жоғарыдан төмен орындалатын командалар тізбегі. Ең алғашқы команда — print(), ол экранға мәтін немесе сан шығарады:

print("Сәлем, Data әлемі!")
print(2026)
print("Жыл:", 2026)

Мәтін (string) тырнақшаға алынады: "..." немесе '...'. Сандар тырнақшасыз жазылады. print ішінде бірнеше мәнді үтірмен берсеңіз, олар бос орынмен бөлініп шығады.

Түсініктеме (comment)

# Бұл жол орындалмайды: ол адамдарға арналған
Python бос орынға (indentation) сезімтал. Әзірге әр команданы жолдың басынан бастаңыз.

4. Жолдар (strings) және f-string

Мәтінмен жұмыс деректі тазалауда өте жиі кездеседі: артық бос орын, әртүрлі регистр, бөлшектеу.

name = "  айгерім  "
print(name.strip())          # "айгерім"
print(name.strip().title())  # "Айгерім"

print(len("SQL"))            # 3

Индекстеу 0-ден басталады: "Python"[0] = "P". Кесінді (slice) [a:b] — a-дан b-ға дейін (b кірмейді).

f-string

5. Шарттар: if, elif, else

Бағдарлама шартқа қарай әртүрлі әрекет жасай алады:

price = 25000
if price >= 100000:
    segment = "қымбат"
elif price >= 10000:
    segment = "орташа"
else:
    segment = "арзан"

Шарттан кейін : қойылады, ал ішкі блок 4 бос орынмен шегініп жазылады. SQL-дегі CASE WHEN-нің дәл баламасы.

Салыстыру және логика

== (тең), !=, >, <, >=, <=. Біріктіру: and, or, not. Тізімде бар ма: city in ["Алматы", "Астана"].

6. Тізімдер (list)

Бір айнымалыда бір ғана мән сақталады. Ал аптаның 7 күнінің сатылымын 7 айнымалыға бөлу ыңғайсыз. Тізім — реттелген мәндер жиыны: нөмірленген сөрелері бар шкаф сияқты, әр сөреде бір мән тұрады. Data-да ол бағанның немесе бірнеше жазбаның қарапайым түрі. Тізім тік жақшамен жазылады, мәндер үтірмен бөлінеді.

Индекс: сөренің нөмірі

sales = [120, 95, 140, 80] тізімі ішінде былай орналасқан:

Индекс0123
Мән1209514080
Теріс индекс-4-3-2-1

Санау 0-ден басталады. Теріс индекс соңынан санайды: -1 — әрқашан соңғы элемент.

sales = [120, 95, 140, 80]
print(sales[0])        # 120 (бірінші)
print(sales[-1])       # 80 (соңғы)
print(sales[1:3])      # [95, 140]
print(len(sales))      # 4
print(sum(sales), max(sales), min(sales))   # 435 140 80
print(sum(sales) / len(sales))              # 108.75

Кесінді sales[1:3] 1-индекстен бастап, 3-индекске дейін алады (3 кірмейді). print-ке бірнеше мәнді үтірмен берсеңіз, олар бір жолда бос орынмен шығады.

Өзгерту және сұрыптау

sales.append(110)      # соңына қосу → [120, 95, 140, 80, 110]
sales.sort()           # орнында сұрыптау → [80, 95, 110, 120, 140]
print(sorted(sales, reverse=True))   # [140, 120, 110, 95, 80]

items = ["Термос", "Блокнот", "Рюкзак"]
items.sort()
print(items)           # ['Блокнот', 'Рюкзак', 'Термос']

Мәтіндер әліпби бойынша сұрыпталады. .sort() тізімнің өзін өзгертеді, ал sorted() жаңа тізім қайтарады, ескісі өзгермейді.

SQL-мен салыстыру

SQLPython list
COUNT(*)len(xs)
SUM, MAX, MINsum(xs), max(xs), min(xs)
AVGsum(xs) / len(xs)
ORDER BY ... DESCsorted(xs, reverse=True)
Тізімнің орташасы: sum(xs) / len(xs). Python-да бөлек avg() жоқ, бірақ statistics.mean() бар. Дөңгелектеу: round(x, 2).

Жиі қателер

  • Индексті 1-ден бастау. 4 элементті тізімде sales[4] жоқ — IndexError. Соңғысы sales[3] немесе sales[-1].
  • xs = xs.sort() жазу. .sort() ештеңе қайтармайды (None), сондықтан тізім жоғалады. Жай xs.sort() жазыңыз.
  • Қазақ әріптерінің реті. Python әріптерді код нөмірі бойынша салыстырады, сондықтан Ә, Қ, Ө, Ү сияқты әріптер кейде күткен орнында тұрмайды.

7. for циклі және range

Кассирді елестетіңіз: ол себеттегі тауарларды бір-бірлеп алып, әрқайсысын сканерлейді. Әрекет бірдей, тек тауар ауысады. for циклі де тізімнің әр элементі үшін бірдей әрекет жасайды. 3 тауар болса да, 3000 тауар болса да, код өзгермейді.

prices = [6500, 7200, 15000]
for p in prices:
    print(round(p * 1.12))
7280
8064
16800

Әр айналымда p айнымалысы келесі мәнді алады: алдымен 6500, сосын 7200, сосын 15000. Шегініспен (4 бос орын) жазылған жолдар — циклдің денесі, олар әр элемент үшін қайталанады. round() бөлшек сандардағы 7280.000000000001 сияқты «қоқысты» алып тастайды.

range: сандар тізбегі

range(n) — 0-ден n−1-ге дейінгі сандар: for i in range(3) → 0, 1, 2. range(1, 4) → 1, 2, 3. Соңғы сан ешқашан кірмейді, сондықтан «1-ден N-ге дейін қоса» үшін range(1, N + 1) жазылады. Цикл ішінде f-string-пен әдемі жол құруға болады: print(f"{i}-күн").

Жинақтаушы (accumulator)

Цикл ішінде мәнді біртіндеп жинау — ең жиі үлгі. Цикл алдында total = 0 қоямыз, ішінде қосамыз, соңында шығарамыз:

total = 0
for p in prices:
    if p > 7000:
        total += p
print(total)   # 22200

Қадам-қадаммен:

Айналымpp > 7000?total кейін
16500жоқ0
27200иә7200
315000иә22200

Бұл SQL-дегі SELECT SUM(price) FROM products WHERE price > 7000 сұрауымен бірдей. Шартты кез келген етіп өзгертуге болады. Мысалы, % — бөліндінің қалдығы: p % 1000 == 0 «1000-ға қалдықсыз бөлінеді» дегенді білдіреді.

enumerate() индекс пен мәнді бірге береді: for i, p in enumerate(prices): → (0, 6500), (1, 7200), (2, 15000).

Жиі қателер

  • total = 0-ді цикл ішіне жазу. Онда ол әр айналымда нөлденеді де, соңында тек соңғы мән қалады.
  • print-тің шегінісі. print(total) цикл ішінде тұрса (шегініспен), ол әр қадамда шығады. Тек қорытынды керек болса, оны шегініссіз жазыңыз.
  • range-тің соңын ұмыту. range(1, 5) — 1, 2, 3, 4. Бес жоқ!

8. while, break, continue

while шарт ақиқат болғанша қайталайды. Қанша рет қайталанатыны алдын ала белгісіз болғанда қолданылады:

balance = 100000
months = 0
while balance < 150000:
    balance = balance * 1.05
    months += 1
print(months)   # 9

break — циклді бірден тоқтатады. continue — қалған бөлігін өткізіп, келесі айналымға өтеді.

Шарт ешқашан жалған болмаса, цикл шексіз жүреді. Бұл платформада 8 секундтан кейін код тоқтатылады.

9. Функциялар

Кофе аппаратын елестетіңіз: оған су мен дәнді саласыз (кіріс), батырманы басасыз, ол кофе береді (шығыс). Ішінде не болатынын әр жолы ойлаудың қажеті жоқ. Функция — атауы бар, қайта қолданылатын код бөлігі. Бір формуланы 10 жерде қайта жазудың орнына, оны бір рет функцияға саламыз. Ол def арқылы анықталады, жақшадағы атаулар — параметрлер (кіріс), return нәтижені қайтарады (шығыс):

def growth_pct(old, new):
    return (new - old) / old * 100

print(growth_pct(80, 100))   # 25.0

Бір функцияны әртүрлі мәндермен шақырамыз. Шақырғанда old бірінші мәнді, new екінші мәнді алады:

ШақыруЕсептеуҚайтарады
growth_pct(80, 100)(100 − 80) / 80 × 10025.0
growth_pct(100, 80)(80 − 100) / 100 × 100-20.0
growth_pct(200, 230)(230 − 200) / 200 × 10015.0

SQL-де ROUND, SUM сияқты дайын функцияларды қолдандыңыз. def — өз функцияңызды жасау тәсілі.

Бірнеше return және if

return орындалған сәтте функция бірден тоқтайды. Сондықтан if/elif ішінде әр тармаққа өз return-ін жазуға болады — SQL-дегі CASE WHEN-нің функция түрі. Сол сияқты қате жағдайды алдын ала тексеруге болады:

def delivery_fee(amount):
    if amount <= 0:
        return 0           # қате сома — бірден шығамыз
    if amount >= 20000:
        return 0
    elif amount >= 10000:
        return 1000
    return 1500

print(delivery_fee(25000), delivery_fee(12000), delivery_fee(5000))   # 0 1000 1500

Нөлге бөлу қаупі болса да, дәл осылай бөлуден бұрын тексеріп, бірден return жасаймыз.

Әдепкі мән

def with_vat(price, rate=0.12):
    return price * (1 + rate)

with_vat(1000)          # 1120.0
with_vat(1000, 0.2)     # 1200.0

Екінші мән берілмесе, rate 0.12 болады.

print мен return әртүрлі: print тек экранға шығарады, ал return мәнді кейін қолдануға болатындай қайтарады. Тексеру тесттері функцияның қайтарған мәнін тексереді.

Жиі қателер

  • return орнына print жазу. Функция экранға санды шығарады, бірақ x = f(...) жазсаңыз, x None болады.
  • return-ді ұмыту. return жоқ функция әрқашан None қайтарады.
  • return-нен кейінгі код. Ол ешқашан орындалмайды. Мысалы, return-нен кейін x = round(x, 2) жазсаңыз, дөңгелектеу болмайды. Оны return жолының өзінде жасаңыз: return round(x, 2).

10. Сөздіктер (dict)

Сөздік — «кілт: мән» жұптары. Бір жазбаны (мысалы бір клиентті) сипаттауға ыңғайлы:

customer = {"name": "Айгерім", "city": "Алматы", "orders": 3}
print(customer["city"])          # Алматы
customer["orders"] += 1
customer["vip"] = True
print(customer.get("phone", "жоқ"))   # кілт жоқ болса, әдепкі мән

Сөздікпен санау

Ең пайдалы үлгі — категориялар бойынша санау (SQL-дегі GROUP BY + COUNT):

cities = ["Алматы", "Астана", "Алматы", "Шымкент", "Алматы"]
counts = {}
for c in cities:
    counts[c] = counts.get(c, 0) + 1
print(counts)   # {'Алматы': 3, 'Астана': 2 ...}

Кілттер мен мәндерді аралау: for key, value in counts.items():

11. List comprehension

Тізімнен жаңа тізім жасаудың қысқа жазуы:

prices = [6500, 7200, 15000, 1200]

# цикл арқылы
with_vat = []
for p in prices:
    with_vat.append(p * 1.12)

# comprehension арқылы
with_vat = [p * 1.12 for p in prices]

# сүзгімен
expensive = [p for p in prices if p > 7000]

Үлгі: [өрнек for элемент in тізім if шарт]. Сөздікке де бар: {k: v for k, v in d.items() if v > 0}.

pandas-та мұндай операциялар бағандармен бірден жасалады, бірақ comprehension Python-ның «тілін» түсінуге көмектеседі.

12. Қателер және try/except

Нақты дерек «лас» келеді: санның орнында мәтін, бос жол. Қате (exception) бағдарламаны тоқтатады. Қатені оқи білу — маңызды дағды:

int("12a")
# ValueError: invalid literal for int() with base 10: '12a'

Соңғы жол қатенің түрін (ValueError) және себебін айтады. Жиі кездесетіндер: NameError (айнымалы жоқ), TypeError (тип сәйкес емес: "5" + 1), KeyError (сөздікте кілт жоқ), ZeroDivisionError, IndentationError.

try / except

raw = ["120", "95", "n/a", "140"]
values = []
for r in raw:
    try:
        values.append(int(r))
    except ValueError:
        print("Өткізілді:", r)
print(sum(values))   # 355
Барлық қатені except: деп жасыруға болмайды. Нақты қате түрін жазыңыз, әйтпесе нағыз қатені байқамай қаласыз.

13. Мини жоба: дүкен сатылымын талдау

Енді үйренгеннің бәрін бір талдауға біріктірейік. Дүкеннің сатылымы CSV мәтін түрінде берілген. Python-ның csv модулі оны сөздіктер тізіміне айналдырады:

import csv, io
rows = list(csv.DictReader(io.StringIO(data)))
print(rows[0])   # {'date': '2024-09-01', 'city': 'Алматы', ...}

Ескеріңіз: CSV-дан оқылған барлық мән — мәтін. Сандарды int() арқылы түрлендіру керек.

Тапсырмалар

  1. Жалпы табыс (qty × price).
  2. Қалалар бойынша табыс (сөздік).
  3. Ең көп табыс әкелген қала.

Бұл — SQL-дағы SUM, GROUP BY және ORDER BY ... LIMIT 1-дің Python нұсқасы. Келесі модульде pandas мұны бір-екі жолмен жасайды.
