M2.1 Python Fundamentals: Python негіздері қазақша

Python — data маманының негізгі тілі. Мұнда кодты браузерде жазып, бірден іске қосасыз. Алғаш іске қосқанда Python ортасы жүктеледі (шамамен 10 МБ), кейін код жылдам орындалады.

Тіркелмей бірінші сабақты бастау Барлық тапсырмалар

1. print және бірінші бағдарлама

Python бағдарламасы — жоғарыдан төмен орындалатын командалар тізбегі. Алғашқы команда — print(): ол экранға мәтін немесе сан шығарады:

print("Сәлем, Data әлемі!")
print(2026)
print("Жыл:", 2026)

Мәтін (string) тырнақшаға алынады: "..." немесе '...'. Сандар тырнақшасыз жазылады. print ішінде бірнеше мәнді үтірмен берсеңіз, олар бос орынмен бөлініп шығады.

Түсініктеме (comment)

# Бұл жол орындалмайды: ол адамдарға арналған
Python шегініске (indentation) сезімтал. Әзірге әр команданы жолдың басынан бастаңыз.

Бағдарлама қалай орындалады?

Python әр жолды кезекпен оқып, орындайды. Төмендегі код екі жол шығарады, себебі екі print бар:

print("Бірінші жол")
print("Екінші жол")

Бір print ішінде бірнеше мән берсеңіз, олар бос орынмен бір жолға шығады: print("Табыс:", 2500, "₸") → Табыс: 2500 ₸.

Жиі қателер

  • Тырнақша жабылмады: print("Сәлем) → SyntaxError. Ашылған тырнақша жабылуы керек.
  • Бас әріп: Print("...") жұмыс істемейді. Python бас және кіші әріптерді ажыратады.
  • Жақша жоқ: print "Сәлем" — Python 2-нің ескі жазуы, қазір қате.
Тапсырма дәл мәтінді күтсе, үтір, бос орын, әріп — бәрі сәйкес келуі керек. Нәтижені «Іске қосу» батырмасымен алдымен өзіңіз тексеріңіз.

Айнымалы (variable) — мәнге берілген атау. Ол = арқылы құрылады:

city = "Алматы"
orders = 120
avg_check = 8450.5
is_active = True

Негізгі типтер

Типті type() көрсетеді. Мәнді бір типтен екіншісіне түрлендіруге болады: int("42"), float("3.5"), str(100).

Айнымалы атауын латын әріптерімен, кіші әріппен жазып, сөздерді _ арқылы бөлеміз: total_revenue. Атау саннан басталмауы керек.

Айнымалының мәнін өзгертуге болады

Айнымалыға жаңа мән берсеңіз, ескі мәні жойылады:

orders = 120
orders = orders + 5     # енді 125
orders += 5             # қысқа жазу, енді 130

= белгісі математикадағы «тең» емес, «сақта» дегенді білдіреді: оң жақтағы мәнді есептеп, сол жақтағы атауға жазады.

Типтер неге маңызды?

Мәтін мен санды қосу мүмкін емес: "1250" + 5 → TypeError. CSV файлдарынан немесе пайдаланушыдан келген деректің бәрі мәтін түрінде келеді, сондықтан есептеу алдында оны int() немесе float() арқылы санға айналдырамыз. Ал мәтіндерді қоссаңыз, олар біріктіріледі: "Ал" + "маты" → "Алматы".

print(type(x)) — айнымалының типін тексерудің ең жылдам тәсілі. Күтпеген нәтиже шықса, алдымен типті қараңыз.

Амалдардың реті

Python математикадағыдай ретті сақтайды: алдымен **, сосын * / // %, соңында + -. Күмәндансаңыз, жақша қойыңыз: (a + b) / 2 мен a + b / 2 әртүрлі нәтиже береді.

Аналитиктің күнделікті формулалары

conversion = buyers / visitors * 100          # конверсия, %
aov = revenue / orders                        # орташа чек
share = part / total * 100                    # үлес, %
change = (new - old) / old * 100              # өзгеріс, %

Бөлшек сандардың ерекшелігі

0.1 + 0.2 нәтижесі 0.30000000000000004 болады. Бұл Python-ның қатесі емес: компьютер бөлшек сандарды екілік жүйеде сақтайды. Нәтижені көрсеткенде round() қолданыңыз, ал ақшаны дәл есептеу керек болса, тиынмен бүтін сан ретінде санаңыз.

Нөлге бөлу ZeroDivisionError береді. Конверсияны есептегенде келушілер саны 0 болуы мүмкін екенін ескеріңіз.

4. Жолдар (strings) және f-string

Мәтінмен жұмыс деректі тазалауда өте жиі кездеседі: артық бос орын, әртүрлі регистр, бөлшектеу.

name = "  айгерім  "
print(name.strip())          # "айгерім"
print(name.strip().title())  # "Айгерім"
print("ALMATY".lower())      # "almaty"
print("a,b,c".split(","))    # ['a', 'b', 'c']
print("2024-09-14"[:7])      # "2024-09"
print(len("SQL"))            # 3

Индекстеу 0-ден басталады: "Python"[0] = "P". Кесінді (slice) [a:b] — a-дан b-ға дейін (b кірмейді).

f-string

Мәнді мәтін ішіне қоюдың ең ыңғайлы тәсілі:

city = "Астана"
orders = 42
print(f"{city}: {orders} тапсырыс")
print(f"Орташа чек: {8450.567:.2f}")   # 8450.57

Пайдалы әдістер

ӘдісМысалНәтиже

Жол әдістері бастапқы жолды өзгертпейді, жаңа жол қайтарады. Сондықтан нәтижені сақтау керек: name = name.strip().

f-string форматтары

revenue = 1234567.891
print(f"{revenue:,.0f}")    # 1,234,568  (мыңдық бөлгішпен)
print(f"{0.2537:.1%}")      # 25.4%

Әдістерді тізбектеп жазуға болады: raw.strip().lower().replace(" ", "_"). Олар солдан оңға қарай орындалады.

5. Шарттар: if, elif, else

Бағдарлама шартқа қарай әртүрлі әрекет жасай алады:

price = 25000
if price >= 100000:
    segment = "қымбат"
elif price >= 10000:
    segment = "орташа"
else:
    segment = "арзан"
print(segment)   # орташа

Шарттан кейін : қойылады, ал ішкі блок 4 бос орынмен шегініп жазылады. Бұл — SQL-дегі CASE WHEN-нің баламасы.

Салыстыру және логика

== (тең), !=, >, <, >=, <=. Біріктіру: and, or, not. Тізімде бар ма: city in ["Алматы", "Астана"].

Шарттардың реті

Python if/elif шарттарын жоғарыдан төмен тексеріп, бірінші ақиқат шарттың блогын ғана орындайды. Сондықтан ең қатаң шартты бірінші жазамыз. Егер price >= 10000 бірінші тұрса, 250 000 ₸-лік тауар да «орташа» болып кетеді.

Шегіністің маңызы

if orders > 100:
    print("Көп")      # шарт ақиқат болса ғана
print("Тексерілді")  # әрқашан орындалады

Шегініс (indentation) қай жол шартқа тиесілі екенін көрсетеді. Шегіністер біркелкі болмаса, IndentationError шығады.

Шартты қысқа жазу

Бір мәнді таңдау үшін бір жолдық өрнек бар: label = "үлкен" if amount > 3000 else "кіші". Ол Excel-дегі IF функциясына ұқсайды.

= мен == белгілерін шатастырмаңыз: біріншісі мән береді, екіншісі салыстырады. if x = 5: синтаксис қатесін береді.

6. Тізімдер (list)

Бір айнымалыда бір ғана мән сақталады. Ал аптаның 7 күнінің сатылымын 7 айнымалыға бөлу ыңғайсыз. Тізім — реттелген мәндер жиыны: нөмірленген сөрелері бар шкаф сияқты, әр сөреде бір мән тұрады. Деректермен жұмыста тізім — бағанның немесе бірнеше жазбаның қарапайым түрі. Тізім тік жақшамен жазылады, мәндер үтірмен бөлінеді.

Индекс: сөренің нөмірі

sales = [120, 95, 140, 80] тізімінің мәндері былай орналасқан:

Индекс0123
Мән1209514080
Теріс индекс-4-3-2-1

Санау 0-ден басталады. Теріс индекс соңынан санайды: -1 — әрқашан соңғы элемент.

sales = [120, 95, 140, 80]
print(sales[0])        # 120 (бірінші)
print(sales[-1])       # 80 (соңғы)
print(sales[1:3])      # [95, 140]
print(len(sales))      # 4
print(sum(sales), max(sales), min(sales))   # 435 140 80
print(sum(sales) / len(sales))              # 108.75

Кесінді sales[1:3] 1-индекстен бастап, 3-индекске дейін алады (3 кірмейді). print-ке бірнеше мәнді үтірмен берсеңіз, олар бір жолда бос орынмен шығады.

Өзгерту және сұрыптау

sales.append(110)      # соңына қосу → [120, 95, 140, 80, 110]
sales.sort()           # орнында сұрыптау → [80, 95, 110, 120, 140]
print(sorted(sales, reverse=True))   # [140, 120, 110, 95, 80]

items = ["Термос", "Блокнот", "Рюкзак"]
items.sort()
print(items)           # ['Блокнот', 'Рюкзак', 'Термос']

Мәтіндер әліпби ретімен сұрыпталады. .sort() тізімнің өзін өзгертеді, ал sorted() жаңа тізім қайтарады, ескісі өзгермейді.

SQL-мен салыстыру

SQLPython list
COUNT(*)len(xs)
SUM, MAX, MINsum(xs), max(xs), min(xs)
AVGsum(xs) / len(xs)
ORDER BY ... DESCsorted(xs, reverse=True)
Тізімнің орташа мәні: sum(xs) / len(xs). Python-да avg() деген бөлек функция жоқ, бірақ statistics.mean() бар. Дөңгелектеу: round(x, 2).

Жиі қателер

  • Индексті 1-ден бастау. 4 элементті тізімде sales[4] жоқ — IndexError. Соңғысы sales[3] немесе sales[-1].
  • xs = xs.sort() жазу. .sort() ештеңе қайтармайды (None), сондықтан xs-ке None жазылып, тізім жоғалады. Жай xs.sort() жазыңыз.
  • Қазақ әріптерінің реті. Python әріптерді код нөмірі бойынша салыстырады, сондықтан Ә, Қ, Ө, Ү сияқты әріптер кейде күткен орнында тұрмайды.

7. for циклі және range

Кассирді елестетіңіз: ол себеттегі тауарларды бір-бірден алып, әрқайсысын сканерлейді. Әрекет бірдей, тек тауар ауысады. for циклі де тізімнің әр элементі үшін бірдей әрекет жасайды. 3 тауар болса да, 3000 тауар болса да, код өзгермейді.

prices = [6500, 7200, 15000]
for p in prices:
    print(round(p * 1.12))
7280
8064
16800

Әр айналымда p айнымалысы келесі мәнді алады: алдымен 6500, сосын 7200, сосын 15000. Шегініспен (4 бос орын) жазылған жолдар — циклдің денесі, олар әр элемент үшін қайталанады. round() бөлшек сандардағы 7280.000000000001 сияқты «қоқысты» алып тастайды.

range: сандар тізбегі

range(n) — 0-ден n−1-ге дейінгі сандар: for i in range(3) → 0, 1, 2. range(1, 4) → 1, 2, 3. Соңғы сан ешқашан кірмейді, сондықтан 1-ден N-ге дейінгі сандарды (N-ді қоса) алу үшін range(1, N + 1) жазылады. Цикл ішінде f-string-пен әдемі жол құруға болады: print(f"{i}-күн").

Жинақтаушы (accumulator)

Цикл ішінде мәнді біртіндеп жинау — ең жиі қолданылатын үлгі. Цикл алдында total = 0 деп бастаймыз, цикл ішінде қосып отырамыз, соңында шығарамыз:

total = 0
for p in prices:
    if p > 7000:
        total += p
print(total)   # 22200

Қадам-қадаммен:

Айналымpp > 7000?кейінгі total
16500жоқ0
27200иә7200
315000иә22200

Бұл SQL-дегі SELECT SUM(price) FROM products WHERE price > 7000 сұрауымен бірдей. Шартты кез келген басқа шартқа ауыстыруға болады. Мысалы, % — бөлгендегі қалдық: p % 1000 == 0 «1000-ға қалдықсыз бөлінеді» дегенді білдіреді.

enumerate() индекс пен мәнді бірге береді: for i, p in enumerate(prices): → (0, 6500), (1, 7200), (2, 15000).

Жиі қателер

  • total = 0-ді цикл ішіне жазу. Онда ол әр айналымда нөлденеді де, соңында тек соңғы мән қалады.
  • print-тің шегінісі. print(total) цикл ішінде тұрса (шегініспен), ол әр қадамда шығады. Тек қорытынды керек болса, оны шегініссіз жазыңыз.
  • range-дің соңын ұмыту. range(1, 5) — 1, 2, 3, 4. Бес жоқ!

8. while, break, continue

while циклі шарт ақиқат болғанша қайталана береді. Қанша рет қайталанатыны алдын ала белгісіз болғанда қолданылады:

balance = 100000
months = 0
while balance < 150000:
    balance = balance * 1.05
    months += 1
print(months)   # 9

break — циклді бірден тоқтатады. continue — циклдің қалған бөлігін өткізіп, келесі айналымға өтеді.

Шарт ешқашан жалған болмаса, цикл шексіз жүреді. Бұл платформада 8 секундтан кейін код тоқтатылады.

for пен while айырмасы

for белгілі тізімді немесе сандар тізбегін аралайды: «әр тапсырыс үшін». while шарт орындалғанша жалғасады: «баланс 150 000-ға жеткенше». Қайталау саны алдын ала белгілі болса, for таңдаңыз: ол қарапайым әрі онда шексіз циклге түсу қаупі жоқ.

break пен continue мысалы

amounts = [2500, 3100, -50, 4200, 0, 1800]
for a in amounts:
    if a == 0:
        break          # 0 — деректің соңын білдіретін белгі
    if a < 0:
        continue       # теріс соманы өткізіп жібереміз
    print(a)
# 2500, 3100, 4200

Цикл 0-ге жеткенде толық тоқтайды, сондықтан 1800 шықпайды. Ал −50 өткізіліп, цикл келесі элементке өтеді.

Әр while циклінің ішінде шартқа әсер ететін айнымалы өзгеретініне көз жеткізіңіз. Мысалдағы balance әр айналымда өседі, сондықтан цикл ерте ме, кеш пе аяқталады.

9. Функциялар

Кофе аппаратын елестетіңіз: оған су мен дәнді саласыз (кіріс), батырманы басасыз, ол кофе береді (шығыс). Ішінде не болатынын әр жолы ойлаудың қажеті жоқ. Функция — атауы бар, қайта қолданылатын код бөлігі. Бір формуланы 10 жерде қайта жазудың орнына, оны бір рет функцияға саламыз. Ол def арқылы анықталады, жақшадағы атаулар — параметрлер (кіріс), return нәтижені қайтарады (шығыс):

def growth_pct(old, new):
    return (new - old) / old * 100

print(growth_pct(80, 100))   # 25.0

Бір функцияны әртүрлі мәндермен шақырамыз. Шақырғанда old бірінші мәнді, new екінші мәнді алады:

ШақыруЕсептеуҚайтарады
growth_pct(80, 100)(100 − 80) / 80 × 10025.0
growth_pct(100, 80)(80 − 100) / 100 × 100-20.0
growth_pct(200, 230)(230 − 200) / 200 × 10015.0

SQL-де ROUND, SUM сияқты дайын функцияларды қолдандыңыз. def — өз функцияңызды жасау тәсілі.

Бірнеше return және if

return орындалған сәтте функция бірден тоқтайды. Сондықтан if/elif ішінде әр тармаққа өз return-ін жазуға болады — SQL-дегі CASE WHEN-нің функция түрі. Сол сияқты қате жағдайды алдын ала тексеруге болады:

def delivery_fee(amount):
    if amount <= 0:
        return 0           # қате сома — бірден шығамыз
    if amount >= 20000:
        return 0
    elif amount >= 10000:
        return 1000
    return 1500

print(delivery_fee(25000), delivery_fee(12000), delivery_fee(5000))   # 0 1000 1500

Нөлге бөлу қаупі болса да, дәл осылай бөлуден бұрын тексеріп, бірден return жасаймыз.

Әдепкі мән

def with_vat(price, rate=0.12):
    return price * (1 + rate)

with_vat(1000)          # 1120.0
with_vat(1000, 0.2)     # 1200.0

Екінші мән берілмесе, rate 0.12 болады.

print мен return әртүрлі: print тек экранға шығарады, ал return мәнді кейін қолдануға болатындай қайтарады. Тексеру тесттері функцияның қайтарған мәнін тексереді.

Жиі қателер

  • return орнына print жазу. Функция экранға санды шығарады, бірақ x = f(...) жазсаңыз, x None болады.
  • return-ді ұмыту. return жоқ функция әрқашан None қайтарады.
  • return-нен кейінгі код. Ол ешқашан орындалмайды. Мысалы, return-нен кейін x = round(x, 2) жазсаңыз, дөңгелектеу болмайды. Оны return жолының өзінде жасаңыз: return round(x, 2).

10. Сөздіктер (dict)

Сөздік — «кілт: мән» жұптары. Бір жазбаны (мысалы бір клиентті) сипаттауға ыңғайлы:

customer = {"name": "Айгерім", "city": "Алматы", "orders": 3}
print(customer["city"])          # Алматы
customer["orders"] += 1
customer["vip"] = True
print(customer.get("phone", "жоқ"))   # кілт жоқ болса, әдепкі мән

Сөздікпен санау

Ең пайдалы үлгі — категориялар бойынша санау (SQL-дегі GROUP BY + COUNT):

cities = ["Алматы", "Астана", "Алматы", "Шымкент", "Алматы"]
counts = {}
for c in cities:
    counts[c] = counts.get(c, 0) + 1
print(counts)   # {'Алматы': 3, 'Астана': 2 ...}

Кілттер мен мәндерді аралау: for key, value in counts.items():

Сөздіктер тізімі: деректер кестесі

Бір сөздік бір жазбаны сипаттаса, сөздіктер тізімі бүтін кестені сипаттайды. Әр сөздік — бір жол, кілттер — баған атаулары:

orders = [
    {"id": 1, "city": "Алматы", "amount": 2500},
    {"id": 2, "city": "Астана", "amount": 3100},
    {"id": 3, "city": "Алматы", "amount": 1800},
]
revenue = {}
for o in orders:
    revenue[o["city"]] = revenue.get(o["city"], 0) + o["amount"]
print(revenue)   # {'Алматы': 4300, 'Астана': 3100}

Бұл SQL-дегі SELECT city, SUM(amount) ... GROUP BY city сұрауымен бірдей.

Жиі қате

Жоқ кілтті d["phone"] арқылы оқысаңыз, KeyError шығады. Кілт болмауы мүмкін болса, d.get("phone") немесе if "phone" in d: қолданыңыз.

11. List comprehension

Тізімнен жаңа тізім жасаудың қысқа жазуы:

prices = [6500, 7200, 15000, 1200]

# цикл арқылы
with_vat = []
for p in prices:
    with_vat.append(p * 1.12)

# comprehension арқылы
with_vat = [p * 1.12 for p in prices]

# сүзгімен
expensive = [p for p in prices if p > 7000]

Үлгі: [өрнек for элемент in тізім if шарт]. Сөздікке де бар: {k: v for k, v in d.items() if v > 0}.

pandas-та мұндай операциялар бағандармен бірден жасалады, бірақ comprehension Python-ның «тілін» түсінуге көмектеседі.

Қашан comprehension, қашан цикл?

Comprehension бір тізімнен жаңа тізім жасағанда жақсы: түрлендіру немесе сүзу. Бірнеше әрекет, print немесе күрделі шарт керек болса, қарапайым for циклі оқуға жеңіл. Ереже: comprehension бір жолға сыймаса, оны циклге айналдырыңыз.

Мысалдар

emails = ["A@MAIL.KZ ", "b@mail.kz"]
clean = [e.strip().lower() for e in emails]

dates = ["2024-11-02", "2024-10-30", "2024-11-15"]
nov = [d for d in dates if d.startswith("2024-11")]

prices = {"латте": 1500, "су": 300}
cheap = {k: v for k, v in prices.items() if v < 1000}
Тізімнің орнына қосынды керек болса, жақшасыз жазуға болады: sum(p * 1.12 for p in prices). Бұл аралық тізім жасамайды.

12. Қателер және try/except

Нақты дерек «лас» келеді: санның орнында мәтін, бос жол. Қате (exception) бағдарламаны тоқтатады. Қатені оқи білу — маңызды дағды:

int("12a")
# ValueError: invalid literal for int() with base 10: '12a'

Соңғы жол қатенің түрін (ValueError) және себебін айтады. Жиі кездесетіндер: NameError (айнымалы жоқ), TypeError (тип сәйкес емес: "5" + 1), KeyError (сөздікте кілт жоқ), ZeroDivisionError, IndentationError.

try / except

raw = ["120", "95", "n/a", "140"]
values = []
for r in raw:
    try:
        values.append(int(r))
    except ValueError:
        print("Өткізілді:", r)
print(sum(values))   # 355
Барлық қатені except: деп жасыруға болмайды. Нақты қате түрін жазыңыз, әйтпесе нағыз қатені байқамай қаласыз.

Traceback-ты оқу

Қате шыққанда Python «ізін» (traceback) көрсетеді. Оны төменнен жоғары оқимыз:

  1. Соңғы жол — қатенің түрі мен себебі.
  2. Оның үстінде — қате болған код жолы және оның нөмірі.
  3. Жоғарыдағы жолдар — сол жерге қалай жеттік (функциялар тізбегі).

Қатені өзіміз көтеру

Функцияға мағынасыз мән келсе, оны үнсіз өткізіп жібергеннен гөрі, анық қате берген дұрыс:

def conversion(visitors, buyers):
    if visitors < 0 or buyers < 0:
        raise ValueError("сандар теріс болмауы керек")
    return buyers / visitors * 100 if visitors else 0

raise қатені бірден тоқтатып, себебін хабарлайды. Мұндай функцияны қолданған адам қатесін бірден көреді.

try блогын тек қате болуы мүмкін жолға қойыңыз. Бүкіл кодты try-ға орасаңыз, қай жерде қате болғанын табу қиын.

13. Мини жоба: дүкен сатылымын талдау

Енді үйренгеннің бәрін бір талдауға біріктірейік. Дүкеннің сатылымы CSV мәтін түрінде берілген. Python-ның csv модулі оны сөздіктер тізіміне айналдырады:

import csv, io
rows = list(csv.DictReader(io.StringIO(data)))
print(rows[0])   # {'date': '2024-09-01', 'city': 'Алматы', ...}

Ескеріңіз: CSV-дан оқылған барлық мән — мәтін. Сандарды int() арқылы түрлендіру керек.

Тапсырмалар

  1. Жалпы табыс (qty × price).
  2. Қалалар бойынша табыс (сөздік).
  3. Ең көп табыс әкелген қала.

Бұл — SQL-дағы SUM, GROUP BY және ORDER BY ... LIMIT 1-дің Python нұсқасы. Келесі модульде pandas мұны бір-екі жолмен жасайды.

Талдауды қадамдарға бөлу

Үлкен тапсырманы бір функцияға жазбаңыз. Әр сұраққа бөлек функция жазып, оларды бір-біріне қосамыз:

def total_revenue(rows): ...
def revenue_by_city(rows): ...
def top_city(rows): ...

Әр функцияны бөлек тексеруге болады, ал top_city ішінде revenue_by_city нәтижесін қайта қолдана аламыз.

Ең үлкен мәнді табу

Сөздіктегі ең үлкен мәнді беретін кілтті табу үшін: max(d, key=d.get). max кілттерді аралап, әрқайсысын d.get арқылы салыстырады.

Нәтижені тексеру

Қалалар бойынша табыстардың қосындысы жалпы табысқа тең болуы керек. Мұндай «тексеру теңдігі» аналитикте маңызды әдет: егер сандар сәйкес келмесе, бір жерде жол жоғалды немесе екі рет саналды.
