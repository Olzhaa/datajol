M2.2 pandas & NumPy: pandas және NumPy қазақша

pandas — Python-дағы деректер талдауының негізгі кітапханасы: кестені (DataFrame) жүктеу, сүзу, топтау, біріктіру және тазалау. Бұл модульде нақты pandas браузеріңізде іске қосылады. Деректер — «Бірінші кофе» желісінің файлдары: orders.csv, customers.csv және daily_sales.csv. SQL-ден білетін әр әрекеттің pandas баламасын үйренесіз.

3. Жаңа бағандар және сұрыптау

Excel-де жаңа баған қосу үшін формуланы бір ұяшыққа жазып, төмен қарай созасыз. pandas-та созудың керегі жоқ: формуланы бүкіл бағанға бір рет жазасыз, ол барлық жолға бірден есептеледі. Мұны векторлау дейді, Python циклы керек емес.

orders['amount_k'] = orders['amount'] / 1000
orders['month'] = orders['order_date'].str[:7]        # '2024-03-05' → '2024-03'
orders['size'] = orders['amount'].apply(lambda x: 'big' if x > 3000 else 'small')

  • Сүзілген кестеге баған қосқанда ескерту шықса, сүзгіден кейін .copy() жазыңыз.

4. groupby: топтау және агрегат

Кассадағы чектерді клиенттер бойынша бөлек үйінділерге бөліп, әр үйіндіні калькулятормен қосып, нәтижелерді бір парақшаға жазып шықтыңыз делік. groupby дәл осыны істейді. Бұл SQL-дегі GROUP BY. Үш қадам: бөлу (split) → есептеу (apply) → біріктіру (combine).

Мысал: қадам-қадаммен

idcustomer_idamount
112000
223000
312500
431500
524000
orders.groupby('customer_id')['amount'].sum()
  1. Split: 1-клиент → [2000, 2500]; 2-клиент → [3000, 4000]; 3-клиент → [1500].
  2. Apply: әр топқа sum: 4500; 7000; 1500.
  3. Combine: бір Series, индексі — customer_id:
customer_id
1    4500
2    7000
3    1500
Name: amount, dtype: int64

Бірнеше агрегат керек болса, .agg() ішінде жаңа_атау=('баған', 'функция') жазамыз. Сол кестеде .agg(orders=('id', 'count'), revenue=('amount', 'sum')).reset_index() мынаны береді:

customer_idordersrevenue
124500
227000
311500

Топтау кілті кестеде болуы керек. Мысалы, ай бойынша топтау үшін алдымен month бағанын қосыңыз (өткен сабақ), сосын groupby('month'). Нәтижені сұрыптау үшін sort_values соңына тіркеледі.

# бір агрегат → Series
orders.groupby('status')['amount'].sum()

# бірнеше агрегат → DataFrame
orders.groupby('customer_id').agg(
    orders=('id', 'count'),
    revenue=('amount', 'sum'),
    avg_check=('amount', 'mean')
).reset_index()

COUNT(*)'count' немесе .size()

WHERE status = 'paid'топтауға дейін сүзгі: orders[orders['status'] == 'paid'].groupby(...)
HAVING SUM(a) > 10агрегаттан кейін сүзгі: res[res['revenue'] > 10]
ORDER BY revenue DESC.sort_values('revenue', ascending=False)
reset_index() топтау бағанын индекстен қайтадан кәдімгі бағанға айналдырады. Нәтижені әрі қарай біріктіру үшін ыңғайлы.

Жиі қателер

  • reset_index() ұмытылады: customer_id индексте қалады, df['customer_id'] қате береді.
  • Сүзгіні ұмыту: refund тапсырыстар да табысқа қосылып кетеді. Алдымен paid қалдырыңыз.
  • 'count' бос емес мәндерді ғана санайды: ('amount', 'count') бос сомаларды есептемейді, ал ('id', 'count') барлық тапсырысты санайды.

6. merge: кестелерді біріктіру

Бір парақта тапсырыстар бар, бірақ клиенттің қаласы мен арнасы жоқ. Екінші парақта клиенттер тізімі бар. Excel-де VLOOKUP арқылы әр тапсырысқа клиенттің деректерін «тартып аласыз». pandas-та бұл merge, SQL-дегі JOIN.

1-клиенттің екі тапсырысы бар, сондықтан оның қаласы екі жолға көшірілді. 4-клиент customers-та жоқ: left жолды сақтайды, бірақ мәндері бос (NaN). how='inner' болса, 13-тапсырыс жойылып, 3 жол қалар еді. 3-клиенттің тапсырысы жоқ, ол тек 'outer'-де шығады.

Біріктіргеннен кейін кез келген бағанмен топтай аласыз: df.groupby('channel')['amount'].sum() → instagram 3500, 2gis 3000.

customers = pd.read_csv('customers.csv')

df = orders.merge(customers, left_on='customer_id', right_on='id',
                  how='left', suffixes=('_order', '_customer'))
howSQL
'inner' (әдепкі)INNER JOIN
'left'LEFT JOIN
'outer'FULL OUTER JOIN

Кілт атаулары бірдей болса: on='customer_id'. Атаулары әртүрлі болса (мұнда customer_id және id), left_on мен right_on жазылады. Екі кестеде де id бағаны болғандықтан, suffixes атауларды ажыратады (әйтпесе id_x, id_y болады).

SQL баламасы:

SELECT o.*, c.city, c.channel
FROM orders o
LEFT JOIN customers c ON c.id = o.customer_id;
Біріктіргеннен кейін жолдар санын тексеріңіз: len(df) күткеннен көп болса, кілт қайталанып тұр.

Жиі қателер

  • on='id' жазу: тапсырыс id-і клиент id-імен салыстырылады, нәтиже қате, бірақ қате хабары шықпайды.
  • Оң жақ кестеде кілт қайталанса, жолдар көбейіп, сомалар екі есе өседі.
  • left-тен кейін сәйкес келмеген жолдарда NaN болады. groupby NaN кілтті әдепкіде тастап кетеді, сондықтан ол сома топтарда көрінбейді.

7. Күндер және pivot_table

CSV-ден оқылған күн — жай мәтін, мысалы '2024-03-05'. Мәтінмен күнді салыстыру, апта күнін табу қиын. pd.to_datetime оны нағыз күнге айналдырады, сосын .dt арқылы оның бөліктерін аламыз.

orders['order_date'] = pd.to_datetime(orders['order_date'])
orders['month'] = orders['order_date'].dt.to_period('M')   # 2024-03
orders['weekday'] = orders['order_date'].dt.day_name()      # 'Tuesday'

Тек айды алу керек болса, мәтін күйінде .str[:7] де жеткілікті (pd-3 сабағы).

pivot_table: жиынтық кесте

Excel-дегі PivotTable сияқты: бір баған жолдарға (index), екіншісі бағандарға (columns) жайылады, қиылысында мәндердің агрегаты (values + aggfunc) тұрады. Бұл «екі өлшемді groupby».

Мысал: тапсырыстар клиенттермен біріктірілген df:

citymonthamount
Алматы2024-012000
Алматы2024-011500
Алматы2024-023000
Астана2024-022500
pd.pivot_table(df, index='city', columns='month',
               values='amount', aggfunc='sum', fill_value=0)
city2024-012024-02
Алматы35003000
Астана02500

Астанада қаңтарда тапсырыс жоқ. fill_value=0 болмаса, ол ұяшықта NaN тұрар еді. Дәл осыны df.groupby(['city', 'month'])['amount'].sum().unstack(fill_value=0) да береді. SQL-де: GROUP BY city, month, ал айларды бағанға жаю үшін SUM(CASE WHEN month = '2024-01' THEN amount END) сияқты әр айға бөлек өрнек керек.

Уақыт қатары

daily_sales.csv — әр аймақтың күндік табысы (day, region, revenue). Аймақ бойынша жиынтық — сол баяғы groupby, тек агрегатты таңдайсыз: sum (жалпы), mean (күніне орташа), max.

daily = pd.read_csv('daily_sales.csv', parse_dates=['day'])
daily.groupby('region')['revenue'].sum()
daily.set_index('day').groupby('region')['revenue'].rolling(3).mean()  # 3 күндік жылжымалы орташа

Мысалы, Алматыда 100 және 120, Астанада 80 және 90 болса, күндік орташа: Алматы 110, Астана 85.

Жиі қателер:
  • Мәтін бағанына .dt қолдану қате береді: алдымен pd.to_datetime.
  • pivot_table-ге біріктірілмеген orders берілсе, city бағаны табылмайды: алдымен merge.
  • aggfunc әдепкіде 'mean': қосынды керек болса, 'sum' деп нақты жазыңыз.

8. NumPy негіздері

NumPy — pandas-тың іргетасы: жылдам сандық массивтер. pandas бағаны ішінде NumPy массиві тұр.

import numpy as np

a = np.array([2150, 2250, 2550, 48000])
a.mean(), np.median(a), a.std()
a * 1.12                         # әр элементке бірден (векторлау)
a[a < 20000]                     # маска арқылы сүзу
np.where(a > 3000, 'big', 'small')

Медиана шектен тыс мәнге (48000) сезімтал емес, ал орташа сезімтал. Мұны статистика модулінен білесіз.

Python циклы миллион жолда баяу. NumPy/pandas операциялары C тілінде орындалады, сондықтан жүздеген есе жылдам.
