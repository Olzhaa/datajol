PY2 Intermediate Python: Intermediate Python қазақша: OOP, генераторлар, декораторлар, файлдар

Python негіздерінен кейінгі қадам: кортеж бен жиын, икемді функциялар, класс пен мұрагерлік, файлдар мен JSON, генераторлар, декораторлар және стандартты кітапхана. Мысалдар — ойындар, дүкен, студенттер мен банк шоты; соңында мәтіндік банк жүйесін өзіңіз құрасыз.

Тапсырмаларды орындау

1. Кортеж (tuple) және жиын (set)

Негіздер курсында тізім (list) мен сөздікті (dict) үйрендіңіз. Python-да тағы екі маңызды жинақ бар: кортеж (tuple) және жиын (set).

Tuple: өзгермейтін тізім

Кортеж дөңгелек жақшамен жазылады. Құрылғаннан кейін оның элементтерін өзгертуге, қосуға не өшіруге болмайды. Сондықтан ол «бірге жүретін» мәндерге ыңғайлы: координата, күн (жыл, ай, күн), ойыншының аты мен ұпайы.

point = (3, 7)
player = ("Айгерім", 1450)
print(point[0])        # 3
# point[0] = 5         # TypeError: кортежді өзгертуге болмайды

name, score = player   # unpacking: мәндерді айнымалыларға тарату
print(name, score)     # Айгерім 1450

a, b = 1, 2
a, b = b, a            # екі айнымалыны бір жолда ауыстыру
print(a, b)            # 2 1

Функция бірнеше мән қайтарғанда (return mn, mx), шын мәнінде бір кортеж қайтарады. Бір элементті кортежде үтір міндетті: (5,). Кортеж өзгермейтіндіктен, оны сөздік кілті ретінде қолдануға болады: {(0, 0): "старт"}.

Set: қайталанбайтын элементтер

Жиын фигуралық жақшамен жазылады және әр мәнді тек бір рет сақтайды. Ретке сенуге болмайды, индексі жоқ. Бірақ in тексерісі өте жылдам.

tags = {"python", "ойын", "python"}
print(len(tags))                   # 2: қайталану жойылды
unique = set([3, 1, 3, 2, 1])      # {1, 2, 3}

chess = {"Әли", "Дана", "Ерлан"}
football = {"Ерлан", "Мадина", "Әли"}
print(chess & football)   # екеуінде де: {'Әли', 'Ерлан'}
print(chess | football)   # бәрі бірге (біріктіру)
print(chess - football)   # тек шахматта: {'Дана'}
print(chess ^ football)   # тек біреуінде ғана

Жиынға .add(x) арқылы қосасыз, .discard(x) арқылы өшіресіз. Бос жиын тек set() арқылы жасалады: {} — бос сөздік.

Қашан не таңдау керек? Реті маңызды, өзгеретін жинақ — list. Өзгермейтін шағын топ — tuple. Қайталанбау және «бар ма?» сұрағы — set. Кілт → мән — dict.

2. Икемді функциялар: default, *args, **kwargs, lambda

Негіздерде функцияны def арқылы жазып, оған дәл қажетті аргументтерді бердіңіз. Нақты бағдарламаларда функция икемді болуы керек: кейбір аргументтер міндетті емес, кейде олардың саны алдын ала белгісіз.

Әдепкі мән (default argument)

def greet(name, greeting="Сәлем"):
    return f"{greeting}, {name}!"

print(greet("Дана"))                 # Сәлем, Дана!
print(greet("Дана", "Қайырлы таң"))  # Қайырлы таң, Дана!
print(greet(greeting="Hi", name="Ali"))  # аты бар (keyword) аргументтер

Әдепкі мәні бар параметрлер міндетті параметрлерден кейін тұрады.

*args: кез келген санды позициялық аргумент

def total(*prices):
    # prices — кортеж: (1200, 800, 450)
    return sum(prices)

print(total(1200, 800, 450))   # 2450
print(total())                 # 0

**kwargs: кез келген атаулы аргумент

def make_order(item, **options):
    # options — сөздік: {'size': 'L', 'color': 'қара'}
    parts = [f"{k}={v}" for k, v in options.items()]
    return item + " (" + ", ".join(parts) + ")"

print(make_order("Футболка", size="L", color="қара"))
# Футболка (size=L, color=қара)

Жұлдызша тізімді «ашып» беру үшін де қолданылады: total(*[100, 200]) — бұл total(100, 200) дегенмен бірдей; f(**{"a": 1}) — f(a=1).

lambda: бір жолдық функция

double = lambda x: x * 2
print(double(21))     # 42
add = lambda a, b: a + b

lambda ішінде тек бір өрнек болады, return жазылмайды. Ол көбіне басқа функцияға «қалай сұрыптау керек» дегенді беру үшін қолданылады (келесі сабақта).

Тұзақ: әдепкі мән ретінде өзгермелі нысан ([], {}) бермеңіз. def add(x, items=[]) — тізім бір рет құрылып, барлық шақыруда ортақ болады. Дұрысы: items=None, ал ішінде if items is None: items = [].

3. sorted, min, max (key) және map, filter, zip, enumerate

Python-да коллекциялармен жұмыс істеуге арналған дайын функциялар бар. Олар циклді қысқартады және кодты оқуға жеңіл етеді.

key: «неге қарап салыстыру керек?»

sorted, min, max функцияларына key беруге болады. Ол — әр элементтен салыстыру мәнін алатын функция.

players = [("Әли", 820), ("Дана", 1450), ("Ерлан", 990)]

ranking = sorted(players, key=lambda p: p[1], reverse=True)
# [('Дана', 1450), ('Ерлан', 990), ('Әли', 820)]
best = max(players, key=lambda p: p[1])     # ('Дана', 1450)
shortest = min(["алма", "жүзім", "өрік"], key=len)   # 'алма'

Бірнеше белгі бойынша сұрыптау үшін key кортеж қайтарады: key=lambda s: (-s["grade"], s["name"]) — алдымен баға бойынша кему, тең болса атымен.

enumerate және zip

names = ["Әли", "Дана", "Ерлан"]
for i, name in enumerate(names, start=1):
    print(i, name)          # 1 Әли, 2 Дана, 3 Ерлан

scores = [820, 1450, 990]
for name, score in zip(names, scores):
    print(name, score)
table = dict(zip(names, scores))   # {'Әли': 820, 'Дана': 1450, 'Ерлан': 990}

zip бірнеше тізімді «тігеді»; ең қысқа тізім біткенде тоқтайды.

map және filter

prices = [1200, 450, 3000]
with_tax = list(map(lambda p: p * 1.12, prices))     # әр элементке функция
cheap = list(filter(lambda p: p < 1000, prices))    # шартқа сай келетіндер: [450]

map мен filter тізім емес, «жалқау» итератор қайтарады (итераторлар туралы кейінірек). Нәтижені көру үшін list(...) орау керек. Көп жағдайда list comprehension бірдей нәрсені анығырақ жазады: [p * 1.12 for p in prices]. Қайсысы түсініктірек болса, соны таңдаңыз.

sorted(xs) жаңа тізім қайтарады, xs.sort() тізімнің өзін өзгертеді. Екеуі де key және reverse қабылдайды.

4. Dict және set comprehension

List comprehension-ды білесіз: [x * 2 for x in xs]. Дәл осы жазу түрі сөздік пен жиынға да бар. Ол «бір коллекциядан екіншісін жасау» міндетін бір жолмен шешеді.

Dict comprehension

Пішімі: {кілт: мән for элемент in коллекция if шарт}.

prices = {"Нан": 250, "Сүт": 520, "Ірімшік": 2400, "Шай": 1300}

# Барлық бағаға 12% ҚҚС қосу
with_vat = {name: round(p * 1.12) for name, p in prices.items()}

# Тек 1000 ₸-ден арзандар
cheap = {name: p for name, p in prices.items() if p < 1000}
# {'Нан': 250, 'Сүт': 520}

# Тізімнен сөздік: сөз → ұзындығы
words = ["алма", "жүзім", "қарбыз"]
lengths = {w: len(w) for w in words}   # {'алма': 4, 'жүзім': 5, 'қарбыз': 6}

# Кілт пен мәнді ауыстыру (мәндер қайталанбаса)
codes = {"ALA": "Алматы", "NQZ": "Астана"}
by_city = {city: code for code, city in codes.items()}

Негізгі құрал — .items(): ол (кілт, мән) жұптарын береді, біз оларды бірден екі айнымалыға таратамыз (өткен сабақтағы unpacking).

Set comprehension

Пішімі дәл сондай, бірақ қос нүкте жоқ: {өрнек for элемент in коллекция}. Нәтижеде қайталанулар өздігінен жойылады.

emails = ["ali@mail.kz", "dana@gmail.com", "erlan@mail.kz"]
domains = {e.split("@")[1] for e in emails}   # {'mail.kz', 'gmail.com'}

names = ["Әли", "Арман", "Дана", "Ерлан", "Динара"]
letters = {n[0] for n in names}               # {'Ә', 'А', 'Д', 'Е'}

Шартты мән

Мән бөлігінде if ... else өрнегін қолдануға болады:

grades = {"Әли": 45, "Дана": 88, "Ерлан": 67}
status = {n: ("өтті" if g >= 50 else "құлады") for n, g in grades.items()}
Comprehension соңындағы if — сүзгі (элементті алып тастайды). Мәннің ішіндегі a if шарт else b — таңдау (элемент қалады, тек мәні өзгереді). Бұларды шатастырмаңыз. Ал логика 2–3 шарттан күрделі болса, кәдімгі for циклін жазған дұрыс: оқуға жеңілірек.

5. Рекурсия

Рекурсия — функцияның өзін-өзі шақыруы. Ол үлкен есепті дәл сондай, бірақ кішірек есепке бөлуге болатын жерде қолданылады: орыс матрешкасын ашқанда ішінен тағы матрешка шығады, ең кішкентайына жеткенде тоқтайсыз.

Екі міндетті бөлік

  • Базалық жағдай (base case) — жауабы бірден белгілі ең қарапайым жағдай. Ол болмаса, функция шексіз шақырыла береді.
  • Рекурсивті қадам — есепті кішірейтіп, функцияның өзін шақыру.
def factorial(n):
    if n <= 1:                    # базалық жағдай
        return 1
    return n * factorial(n - 1)   # рекурсивті қадам

print(factorial(5))   # 120

Не болып жатыр? factorial(5) = 5 × factorial(4) = 5 × 4 × factorial(3) = … = 5 × 4 × 3 × 2 × 1. Әр шақыру өз нәтижесін күтіп «стекте» тұрады, базалық жағдайға жеткенде жауаптар кері қарай жиналады.

Мысал: санның цифрларын қосу

def digit_sum(n):
    if n < 10:
        return n
    return n % 10 + digit_sum(n // 10)

print(digit_sum(2026))   # 2 + 0 + 2 + 6 = 10

Рекурсия қай жерде шынымен ыңғайлы?

Ағаш тәрізді құрылымдарда: папкалар ішіндегі папкалар, тізім ішіндегі тізімдер, мәзір ішіндегі мәзірлер. Мұнда цикл жазу қиын, ал рекурсия табиғи:

def count_files(folder):
    # folder — тізім: ішінде файл атаулары (str) немесе ішкі папкалар (list)
    total = 0
    for item in folder:
        if isinstance(item, list):
            total += count_files(item)   # ішкі папкаға «кіреміз»
        else:
            total += 1
    return total

disk = ["a.txt", ["b.png", "c.png", ["d.mp3"]], "e.pdf"]
print(count_files(disk))   # 5
Python рекурсия тереңдігін шектейді (әдетте ~1000). Тым терең болса — RecursionError. Қарапайым санауға цикл жеткілікті; рекурсияны ағаш тәрізді деректерге және «бөліп ал да жең» алгоритмдеріне сақтаңыз. Сондай-ақ fib(n) = fib(n-1) + fib(n-2) сияқты аңғал рекурсия бір есепті қайта-қайта шешеді, сондықтан баяу.

6. Класстар мен объектілер

Осы уақытқа дейін деректер (сөздік, тізім) мен оларды өңдейтін функциялар бөлек өмір сүрді. Класс оларды біріктіреді: бір «нәрсенің» күйі (attributes) және оның әрекеттері (methods) бір жерде тұрады. Класс — сызба (чертеж), ал объект (instance) — сол сызба бойынша жасалған нақты зат.

Алғашқы класс

class Student:
    school = "№25 мектеп"            # класс атрибуты: барлық студентке ортақ

    def __init__(self, name, grade):
        self.name = name               # объект атрибуттары
        self.grade = grade
        self.marks = []

    def add_mark(self, mark):          # әдіс (method)
        self.marks.append(mark)

    def average(self):
        if not self.marks:
            return 0
        return sum(self.marks) / len(self.marks)

    def __str__(self):
        return f"{self.name} ({self.grade}-сынып)"

    def __repr__(self):
        return f"Student({self.name!r}, {self.grade})"

ali = Student("Әли", 9)       # __init__ шақырылады
ali.add_mark(5); ali.add_mark(4)
print(ali.average())           # 4.5
print(ali)                     # Әли (9-сынып)  ← __str__
print([ali])                   # [Student('Әли', 9)]  ← __repr__
print(ali.school)              # №25 мектеп

Негізгі ұғымдар

  • __init__ — конструктор: объект жасалғанда бір рет орындалып, бастапқы күйді орнатады.
  • self — «осы объектінің өзі». Әр әдістің бірінші параметрі. ali.add_mark(5) шын мәнінде Student.add_mark(ali, 5).
  • Объект атрибуты (self.name) әр объектіде өзінше. Класс атрибуты (school) класқа тиесілі және барлығына ортақ; оны Student.school арқылы өзгертсеңіз, бәрінде өзгереді.
  • __str__ — адамға арналған әдемі мәтін (print, str()). __repr__ — әзірлеушіге арналған нақты сипаттама (консоль, тізім ішінде көрсету).
Класс атрибутын өзгерту үшін self.count += 1 емес, ClassName.count += 1 жазыңыз. Әйтпесе Python объектіге жаңа атрибут жасап қояды да, ортақ мән өзгермейді.

7. Мұрагерлік, super(), полиморфизм және dunder әдістер

Кейде бір класс екіншісінің «ерекше түрі» болады: жинақ шоты — банк шотының бір түрі, ит — жануардың бір түрі. Мұндай кезде кодты қайталамай, мұрагерлік (inheritance) қолданамыз: бала класс (child) ата класстың (parent) барлық атрибуттары мен әдістерін алады және өзінікін қосады.

class Account:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance

    def deposit(self, amount):
        self.balance += amount

class SavingsAccount(Account):            # Account-тан мұра алады
    def __init__(self, owner, balance=0, rate=0.1):
        super().__init__(owner, balance)  # ата класстың __init__-і
        self.rate = rate

    def add_interest(self):
        self.balance += self.balance * self.rate

s = SavingsAccount("Дана", 10000)
s.deposit(5000)        # әдіс Account-тан келді
s.add_interest()
print(s.balance)       # 16500.0
print(isinstance(s, Account))   # True

super() — ата класқа сілтеме. Ол ата класс жасайтын жұмысты қайталамауға мүмкіндік береді.

Полиморфизм: бір әдіс, әртүрлі әрекет

class Animal:
    def speak(self):
        return "..."

class Dog(Animal):
    def speak(self):            # әдісті қайта анықтау (override)
        return "Ау-ау"

class Cat(Animal):
    def speak(self):
        return "Мияу"

for a in [Dog(), Cat(), Animal()]:
    print(a.speak())            # Ау-ау, Мияу, ...

Цикл объектінің нақты класын білмейді, тек speak() әдісі бар екенін біледі. Осыған дейін жазған кодыңыз жаңа класстармен де өзгеріссіз жұмыс істейді.

Dunder әдістер: Python операторларын үйрету

Екі асты сызықпен қоршалған әдістер (double underscore, «dunder») класты Python-ның кірістірілген мүмкіндіктеріне қосады:

class Song:
    def __init__(self, title, seconds):
        self.title, self.seconds = title, seconds
    def __eq__(self, other):     # ==
        return self.title == other.title and self.seconds == other.seconds
    def __lt__(self, other):     # <  (sorted, min, max осыны қолданады)
        return self.seconds < other.seconds

class Playlist:
    def __init__(self):
        self.songs = []
    def __len__(self):           # len(playlist)
        return len(self.songs)

Басқалары: __add__ (+), __contains__ (in), __getitem__ (p[0]).

__eq__ анықталмаса, == екі айнымалы бір объектіге сілтейтінін ғана тексереді: мәндері бірдей екі Song «тең емес» болып шығады.

8. Модульдер мен import

Бағдарлама өскен сайын барлық кодты бір файлға сыйғызу қиын. Модуль — жай ғана .py файл; ондағы функциялар мен кластарды басқа файлда import арқылы қолдануға болады. Бірнеше модуль бір папкада жиналса (__init__.py файлымен), ол пакет (package) деп аталады.

Импорттың төрт түрі

import math                    # бүкіл модуль: math.sqrt(16)
from math import sqrt, pi      # тек керек атаулар: sqrt(16)
import datetime as dt          # қысқа лақап ат (alias): dt.date.today()
from random import *           # бәрін — ұсынылмайды: атаулар қайдан келгені түсініксіз

Python стандартты кітапханасында жүздеген модуль бар: math, random, datetime, json, collections, string, os, pathlib. Сырттан орнатылатын пакеттер (мысалы, requests) терминалда pip install requests арқылы қосылады.

Өз модуліңізді жазу

# shop_utils.py
VAT = 0.12

def with_vat(price):
    return round(price * (1 + VAT))

if __name__ == "__main__":
    # тек файлды тікелей іске қосқанда орындалады
    print(with_vat(1000))
# main.py
from shop_utils import with_vat
print(with_vat(2500))      # 2800

if __name__ == "__main__" не үшін керек?

Әр модульде __name__ деген арнайы айнымалы бар. Файлды тікелей іске қоссаңыз (python shop_utils.py), оның мәні "__main__" болады. Ал файл басқа жерден импортталса, мәні — модуль аты ("shop_utils"). Сондықтан бұл шарттың ішіндегі код (тесттер, демо, бағдарламаның басталуы) импорт кезінде орындалмайды. Мұнсыз import жасағанда күтпеген print-тер шығып кетер еді.

Модуль бір рет қана жүктеледі: екінші import оны қайта орындамайды. Файлдарыңызды стандартты модуль атымен атамаңыз (random.py, json.py): Python сіздің файлыңызды импорттап, қате береді.

9. Файлдар: open, with және json

Айнымалылар бағдарлама жабылғанда жоғалады. Деректі сақтап қалу үшін оны файлға жазамыз. (Бұл беттегі Python браузер ішіндегі виртуалды файл жүйесімен жұмыс істейді, сондықтан файлдарды еркін жазып-оқи аласыз.)

open және with

with open("todo.txt", "w", encoding="utf-8") as f:
    f.write("Сабақ оқу\n")
    f.write("Дүкенге бару\n")

with open("todo.txt", encoding="utf-8") as f:
    lines = [line.strip() for line in f]
print(lines)    # ['Сабақ оқу', 'Дүкенге бару']

with блогы аяқталғанда файл өздігінен жабылады, тіпті ішінде қате болса да. Сондықтан f = open(...) … f.close() орнына әрқашан with жазыңыз.

РежимМағынасы
"r"оқу (әдепкі); файл жоқ болса — FileNotFoundError
"w"жазу; бар файлдың ішін өшіріп, қайта жазады
"a"соңына қосу (append)

Оқу тәсілдері: f.read() — бүкіл мәтін бір жолмен; f.readlines() — жолдар тізімі; for line in f — жолма-жол (үлкен файлдарға ең үнемді). Әр жолдың соңында \n болады, оны .strip() алып тастайды. Қазақ әріптері дұрыс сақталуы үшін encoding="utf-8" жазыңыз.

json: құрылымды деректі сақтау

Сөздіктер мен тізімдерді мәтін ретінде сақтаудың стандартты пішімі — JSON. Ол веб-API-лерде де, баптау файлдарында да қолданылады.

import json

stock = {"Нан": 40, "Сүт": 25, "Шай": 12}

with open("stock.json", "w", encoding="utf-8") as f:
    json.dump(stock, f, ensure_ascii=False, indent=2)   # файлға жазу

with open("stock.json", encoding="utf-8") as f:
    loaded = json.load(f)                                 # файлдан оқу

text = json.dumps(stock, ensure_ascii=False)   # жолға: '{"Нан": 40, ...}'
back = json.loads(text)                        # жолдан сөздікке

Есте сақтау тәсілі: s әрпі бар нұсқа (dumps, loads) — string-пен жұмыс істейді, онсыз — файлмен. ensure_ascii=False кириллицаны \u04d8 сияқты кодқа айналдырмай, оқылатын күйде сақтайды.

JSON-да кортеж жоқ (тізімге айналады), ал сөздік кілттері тек жол бола алады: {1: "a"} сақталып, қайта оқылғанда {"1": "a"} болады.

10. Итераторлар және генераторлар (yield)

for x in ... тізіммен де, жолмен де, сөздікпен де, файлмен де жұмыс істейді. Неге? Себебі олардың бәрі итерацияланатын (iterable). for циклі іште мынаны жасайды:

queue = ["Әли", "Дана", "Ерлан"]
it = iter(queue)      # итератор алу
print(next(it))       # Әли
print(next(it))       # Дана
print(next(it))       # Ерлан
next(it)              # StopIteration: элемент бітті → for циклі осы жерде тоқтайды

Итератор — «келесі элементті бер» дегенді білетін объект. Ол орнын есте сақтайды және бір рет қана өтеді: біткен итераторды қайта бастау үшін жаңасын алу керек.

Генератор: yield бар функция

Өз итераторыңызды жасаудың ең оңай жолы — генератор. Бұл return орнына yield қолданатын функция. Әр yield бір мән береді де, функция сол жерде «кідіреді». Келесі next() келгенде, ол тоқтаған жерінен жалғасады.

def countdown(n):
    while n > 0:
        yield n
        n -= 1
    print("Старт!")

for x in countdown(3):
    print(x)          # 3, 2, 1, сосын «Старт!»

gen = countdown(2)    # әзірге ештеңе орындалған жоқ!
print(next(gen))      # 2

Неге бұл пайдалы?

  • Жад үнемдеу. Генератор барлық мәнді алдын ала тізімге жинамайды, оларды біртіндеп жасайды. Миллион жолдық файлды оқу немесе шексіз тізбек жасау мүмкін болады.
  • Шексіз тізбектер. while True: yield ... — тапсырыс нөмірлері, ойындағы кезек, ID генераторы.
  • Конвейер. Бір генератор екіншісін «қоректендіреді»: файл жолдары → тазалау → сүзу.
def order_ids():
    n = 1
    while True:              # шексіз, бірақ жалқау
        yield f"ORD-{n:04d}"
        n += 1

ids = order_ids()
print(next(ids), next(ids))  # ORD-0001 ORD-0002

Генератор өрнегі

List comprehension-ды дөңгелек жақшаға алсаңыз, генератор шығады: total = sum(p * q for p, q in cart). Мұнда аралық тізім құрылмайды.

Генераторды бір рет қана аралай аласыз. g = (x for x in range(3)); list(g) → [0, 1, 2], ал екінші рет list(g) → [].

11. Декораторлар

Python-да функция — кәдімгі объект: оны айнымалыға жазуға, басқа функцияға беруге және функциядан қайтаруға болады. Декоратор осыған негізделген: ол функцияны қабылдап, оны «орап» (wrap), жаңа мүмкіндік қосылған функцияны қайтарады. Бастапқы функцияның кодына қол тигізбейміз.

Қадамдап құру

def log_calls(func):                  # функцияны қабылдайды
    def wrapper(*args, **kwargs):     # кез келген аргументті өткізеді
        print(f"→ {func.__name__}{args}")
        result = func(*args, **kwargs)   # бастапқы функцияны шақыру
        print(f"← {result}")
        return result
    return wrapper                    # жаңа функцияны қайтарады

@log_calls                            # бұл: add = log_calls(add)
def add(a, b):
    return a + b

add(2, 3)
# → add(2, 3)
# ← 5

@log_calls жазуы — add = log_calls(add) дегеннің қысқа түрі. Енді add атауы wrapper-ге сілтейді, ал wrapper ішінде бастапқы func сақталған (бұл closure деп аталады: ішкі функция сыртқы функцияның айнымалыларын «есте сақтайды»).

functools.wraps

Орағаннан кейін add.__name__ мәні "wrapper" болып кетеді, бұл жөндеуді (debug) қиындатады. Түзету оңай:

from functools import wraps

def log_calls(func):
    @wraps(func)              # атауды, docstring-ті сақтайды
    def wrapper(*args, **kwargs):
        ...

Нақты қолданыс

  • Тексеру: аргумент дұрыс па, пайдаланушы кірген бе (веб-фреймворктардағы @login_required).
  • Уақытты өлшеу және логтау.
  • Кэш: стандартты @functools.lru_cache бұрын есептелген нәтижелерді сақтайды; аңғал рекурсивті fib бірден жылдамдайды.
  • Веб-маршруттар: Flask/FastAPI-дегі @app.get("/users") де декоратор.
Декоратор жазғанда wrapper ішінде return func(...) нәтижесін қайтаруды ұмытпаңыз. Әйтпесе безендірілген функция әрқашан None қайтарады.

12. datetime және collections

Стандартты кітапханадағы екі модуль күнделікті кодта өте жиі кездеседі: күн мен уақытқа арналған datetime және арнайы жинақтар беретін collections.

datetime

from datetime import date, datetime, timedelta

start = date(2026, 9, 1)                # 1 қыркүйек 2026
deadline = start + timedelta(days=30)   # 30 күннен кейін
print(deadline)                         # 2026-10-01
print((date(2026, 12, 16) - start).days)   # 106: айырма — timedelta

now = datetime(2026, 10, 16, 14, 30)
print(now.strftime("%d.%m.%Y %H:%M"))   # 16.10.2026 14:30  (күн → мәтін)
d = datetime.strptime("22.03.2027", "%d.%m.%Y")   # мәтін → күн
print(d.weekday())                      # 0 = дүйсенбі … 6 = жексенбі

strftime — format (күнді жолға), strptime — parse (жолды күнге). Жиі кодтар: %Y жыл, %m ай, %d күн, %H:%M сағат пен минут.

Counter: санау

from collections import Counter

votes = ["Дана", "Әли", "Дана", "Ерлан", "Дана", "Әли"]
c = Counter(votes)
print(c["Дана"])          # 3
print(c.most_common(2))   # [('Дана', 3), ('Әли', 2)]
print(c["Тимур"])         # 0: жоқ кілтке қате бермейді

defaultdict: әдепкі мәні бар сөздік

from collections import defaultdict

by_class = defaultdict(list)
for name, cls in [("Әли", "9А"), ("Дана", "9Б"), ("Ерлан", "9А")]:
    by_class[cls].append(name)    # кілт жоқ болса, бос тізім өздігінен жасалады
# {'9А': ['Әли', 'Ерлан'], '9Б': ['Дана']}

Кәдімгі сөздікте if cls not in d: d[cls] = [] деп тексеру керек еді. defaultdict(int) санауға ыңғайлы (әдепкі 0).

namedtuple: атаулы өрістері бар кортеж

from collections import namedtuple

Point = namedtuple("Point", ["x", "y"])
p = Point(3, 4)
print(p.x, p[1])     # 3 4: атауымен де, индексімен де
x, y = p             # кортеж сияқты таратылады

Шағын, өзгермейтін жазбаға (координата, түс, ойын картасы) толық класс жазудың қажеті жоқ: namedtuple жеткілікті және оқуға p[0]-ден әлдеқайда түсінікті.

collections ішінде deque да бар: кезектің екі шетінен де жылдам қосып-алуға арналған (appendleft, popleft).

13. Мини жоба: мәтіндік банк жүйесі

Модульде үйренгенді бір жобаға жинаймыз: шағын банк жүйесі. Онда клиенттер шот ашады, ақша салады, алады және бір-біріне аударады. Нақты банк қосымшасының «ядросы» дәл осындай класстардан тұрады, тек оған дерекқор мен интерфейс қосылады.

1-қадам: жобалау

Код жазбас бұрын «қандай объектілер бар және не істейді?» деп сұраңыз:

КлассКүйі (атрибуттар)Әрекеттері (әдістер)
BankAccountowner, balance, historydeposit, withdraw, __str__
Bankaccounts: сөздік (аты → шот)open_account, transfer, total, richest
InsufficientFundsөз қате класымыз: қаражат жеткіліксіз

2-қадам: өз қатеңіз

class InsufficientFunds(Exception):
    pass

raise InsufficientFunds("Балансыңыз: 3000 ₸")

Exception-нан мұра алатын бос класс жеткілікті. Енді шақырушы код except InsufficientFunds: арқылы дәл осы жағдайды ұстай алады, ал басқа қателер (мысалы, теріс сома үшін ValueError) бөлек өңделеді.

3-қадам: шот

class BankAccount:
    def __init__(self, owner, balance=0):
        self.owner = owner
        self.balance = balance
        self.history = []                    # ("deposit", 5000) сияқты кортеждер

    def deposit(self, amount):
        if amount <= 0:
            raise ValueError("Сома оң болуы керек")
        self.balance += amount
        self.history.append(("deposit", amount))

withdraw да осылай, тек алдымен балансты тексереді. Маңызды қағида: алдымен тексер, сосын өзгерт. Егер балансты азайтып, кейін қате көтерсеңіз, шот «жартылай өзгерген» күйде қалады.

4-қадам: банк және аударым

Аударым — екі операция: біреуінен алу, екіншісіне салу. Егер алу сәтсіз болса (ақша жетпесе), салу орындалмауы керек. withdraw қате көтерсе, келесі жол орындалмайды, сондықтан реті дұрыс болса жеткілікті:

def transfer(self, src, dst, amount):
    self.accounts[src].withdraw(amount)   # қате болса, осы жерде тоқтайды
    self.accounts[dst].deposit(amount)

Әрі қарай

Жобаны дамыту идеялары: шоттарды json файлға сақтау және жүктеу; әр операцияға datetime уақытын қосу; ай сайынғы пайыз есептейтін SavingsAccount мұрагері; input() арқылы мәзір (компьютердегі Python-да). Бұл беттегі Python input()-ты қолдамайды, сондықтан мәндерді айнымалыларға тікелей жазамыз.

Әр әдіс бір ғана жұмыс істесін және оны тест арқылы бірден тексеріңіз: assert acc.balance == 15000. Шағын қадамдармен жазылған жобаны жөндеу оңай.
